입력(Input) · 처리(Process) · 출력(Output) 이해하기
컴퓨터는 입력(INPUT) 된 데이터를 처리(PROCESS) 한 뒤, 그 결과를 출력
(OUTPUT) 합니다. 이 과정을 일상생활의 예시인 라면 끓이기로 살펴보겠습니다.
물
라면(면, 스프)
냄비
입력 (Input)
1.냄비에 물을 넣고 끓입니다.
2.스프를 넣습니다.
3.면을 넣고 정해진 시간 동안 끓입니다.
4.라면이 익으면 불을 끕니다.
처리(Process)
맛있게 완성된 라면
출력(Output)
입력된 재료를 순서대로 처리하면, 원하는 결과(완성된 라면)가 출력됩니다.
컴퓨터도 이와 같은 원리로 데이터를 처리하여 결과를 만들어 냅니다.

코코봇과 프로그램을 연결하여 동작시키는 방법을 이해할 수 있다.
TextField를 이용하여 이동거리와 회전각도를 입력받을 수 있다.
Button을 이용하여 코코봇의 이동과 회전 기능을 실행할 수 있다.
사용자가 입력한 값에 따라 코코봇이 움직이도록 프로그램을 구성할 수 있다.
학습 목표
지금까지는 화면 안에서 버튼을 누르거나 값을 입력하여 프로그램의 기능을 실행해보았습니다.
이번에는 프로그램의 명령을 실제 코코봇의 움직임과 연결해봅니다.
사용자가 이동거리나 회전각도를 입력하고 버튼을 누르면, 입력한 값에 따라
코코봇이 앞으로 이동하거나 왼쪽·오른쪽으로 회전하도록 만들 수 있습니다.
코코봇 제어의 기본 흐름
값 입력 → 버튼 클릭 → 명령 전달 → 코코봇 동작
예를 들어,
이동거리에 100을 입력하고 앞으로 이동 버튼을 누르면 정해진 거리만큼 이동합니다.
회전각도에 90을 입력하고 왼쪽 회전 버튼을 누르면 90도 왼쪽으로 회전합니다.
같은 값을 이용하여 오른쪽 회전도 실행할 수 있습니다.
