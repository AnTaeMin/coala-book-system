# 이 교재로 배우는 방법

## 작은 기능부터 만들기

이 교재는 코딩 입문자를 위한 16차시 과정입니다. 원하는 기능을 말로 설명하고, AI가 제안한 내용을 실행하며 앱을 완성합니다. 한 번에 기능 하나를 요청하세요.

## 예상과 실제 비교하기

실습 전 입력과 예상 결과를 적습니다. 실행한 뒤 실제 결과를 비교하고, 정상 입력뿐 아니라 빈 입력과 경계값도 확인합니다. 오류가 나면 같은 입력으로 다시 확인하세요.

## 예시와 내 결과 구분하기

AI 응답은 집필 예시이며 실제 서비스의 답변이 아닙니다. 그림은 PDF 원본 또는 교사용 예제입니다. 자기 앱의 실행 화면과 개발 기록을 별도로 남기세요.
:::

# AI와 첫 앱 만들기
## 1차시 · 요청하고 실행하고 확인하기

### 학습 목표

- 바이브 코딩의 기본 과정을 설명할 수 있다.
- 원하는 동작을 짧은 문장으로 요청할 수 있다.
- 앱을 실행하여 요청한 결과와 비교할 수 있다.

### 오늘의 시작

앱을 만드는 첫걸음은 원하는 동작을 말로 설명하는 것입니다. 오늘은 버튼으로 인사 알림창을 여는 앱을 만들고, AI의 설명과 실제 동작이 같은지 확인합니다.
:::

:::page{type="concept" id="ch01-concept" layout="basic"}
# 만들기는 AI와 함께, 확인은 내가

## 개념 이해하기

이 교재에서 바이브 코딩은 자연어로 요구를 설명하고, AI가 제안한 코드나 기능을 실행하며 수정하는 활동입니다. 자연어는 우리가 평소에 쓰는 말입니다.

AI는 빠르게 초안을 만들 수 있지만, 내가 원하는 동작과 다른 결과를 만들 수도 있습니다. 작동하는지 확인하는 일까지 해야 앱 만들기가 끝납니다.
:::

:::page{type="concept" id="ch01-verification" layout="basic"}
# AI 결과를 검증하는 습관

## 자신 있는 설명도 확인하기

AI가 사실이 아닌 내용을 그럴듯하게 답하는 현상을 환각이라고 합니다. 설명의 사실은 공식 자료와 대조하고, 앱의 동작은 직접 실행해 확인합니다.

## 입력할 자료 고르기

수업용 예시 데이터를 사용합니다. 개인정보, 비밀번호, API 인증키는 AI 요청과 제출 화면에 넣지 않습니다. 캡처하기 전에 주소창과 코드도 확인합니다.

## 도움 받은 과정 밝히기

AI가 만든 초안과 내가 수정하고 확인한 부분을 개발 기록에서 구분합니다. 오류를 발견한 과정도 학습 결과입니다.
:::


## 5차시 · 입력한 두 수로 덧셈하기

### 학습 목표

- 변수의 역할과 문자·숫자의 차이를 설명할 수 있다.
- 숫자 입력으로 덧셈 앱을 만들 수 있다.
- 잘못된 입력에서 계산하지 않도록 요청할 수 있다.

### 오늘의 시작

입력창에 적힌 숫자는 계산하기 전에 숫자로 해석해야 합니다. 이번에는 두 수를 더하는 계산기를 만들고, 빈 입력과 문자를 넣었을 때도 확인합니다.
:::

:::page{type="concept" id="ch05-concept" layout="basic"}
# 문자를 잇는 것과 수를 더하는 것

## 개념 이해하기

변수는 값을 보관하고 이름으로 다시 사용하는 방법입니다. 입력창에 적은 2와 3을 문자로 이어 붙이면 23이지만, 숫자로 바꿔 더하면 5입니다.

이번 앱은 부호가 있는 정수 두 개를 받습니다. 빈 입력, 소수, 숫자가 아닌 문자는 계산하지 않고 정수를 입력하라는 안내를 보여줍니다.
:::

:::page{type="concept" id="ch05-roles" layout="cards"}
# 핵심 요소 살펴보기

## 입력값

사용자가 적은 내용을 읽습니다.

## 숫자 변환

계산할 수 있는 정수인지 확인합니다.

## 계산과 출력

두 정수를 더하고 합계를 보여줍니다.
:::

:::page{type="step-process" id="ch05-design"}
# 만들기 전에 정하기

## 입력과 버튼 정하기

첫 번째 수, 두 번째 수 입력창과 더하기 버튼을 둡니다.

## 계산 규칙 정하기

두 입력을 각각 정수로 바꾼 뒤 + 연산으로 더합니다. 입력 문자열을 코드로 실행하는 eval은 사용하지 않습니다.

## 실패 결과 정하기

입력이 올바르지 않으면 이전 숫자 결과 대신 정수 입력 안내를 보여줍니다.
:::

:::page{type="concept" id="ch05-code" layout="basic"}
# 같은 입력, 다른 계산

## 코드와 실행 결과

첫 줄은 문자를 이어 붙입니다. 두 번째 줄은 정수로 바꾼 값을 더합니다. 입력이 올바른 정수일 때의 짧은 예시입니다.

```python
first = "2"
second = "3"
print(first + second)
print(int(first) + int(second))
```

```output
23
5
```

# 조건으로 결과 나누기
## 6차시 · 기준값 앞뒤를 확인하기

### 학습 목표

- 조건의 참과 거짓에 따른 동작을 설명할 수 있다.
- 정해진 기준에 따라 안내하는 앱을 만들 수 있다.
- 기준값의 바로 앞과 기준값을 테스트할 수 있다.

### 오늘의 시작

앱은 입력값에 따라 다른 안내를 할 수 있습니다. 현재 빌린 책이 세 권 미만이면 추가 대출 가능, 세 권 이상이면 추가 대출 불가로 안내하는 연습 앱을 만듭니다.
:::

:::page{type="concept" id="ch06-concept" layout="basic"}
# 조건에는 분명한 기준이 필요하다

## 개념 이해하기

책을 많이 빌렸나요라는 질문은 사람마다 다르게 판단할 수 있습니다. 현재 빌린 책이 3권 미만인가라는 조건은 같은 입력에서 같은 판단을 할 수 있습니다.

조건문은 조건에 따라 실행할 일을 나누는 구조입니다. 이번 실습의 세 권 기준은 수업용 규칙이며 실제 도서관 정책을 뜻하지 않습니다.
:::

:::page{type="concept" id="ch06-roles" layout="cards"}
# 핵심 요소 살펴보기

## 참인 경우

현재 대출 수가 3 미만이면 추가 대출 가능입니다.

## 거짓인 경우

현재 대출 수가 3 이상이면 추가 대출 불가입니다.

## 입력 오류

0~10 사이의 정수가 아니면 입력 안내를 합니다.
:::

:::page{type="step-process" id="ch06-design"}
# 만들기 전에 정하기

## 입력 범위 정하기

현재 빌린 책 수를 0~10 사이의 정수로 받습니다.

## 조건 적기

입력이 올바른지 먼저 확인하고, 3 미만인지 판단합니다.

## 안내 정하기

가능, 불가, 입력 안내를 구분하여 보여줍니다.
:::

:::page{type="concept" id="ch06-code" layout="basic"}
# 조건문 읽어보기

## 코드와 실행 결과

비교가 참이면 if 아래를, 거짓이면 else 아래를 실행합니다. 이 예시는 올바른 정수 입력만 다룹니다.

```python
borrowed = 3
if borrowed < 3:
    print("추가 대출 가능")
else:
    print("추가 대출 불가")
```

```output
추가 대출 불가
```
:::

4단은 4에 1부터 9까지 차례로 곱합니다. 반복은 정한 횟수만큼 하거나 조건이 참인 동안 이어갈 수 있습니다. 이번 앱은 아홉 번 반복합니다.

이번 앱의 출력은 아홉 줄이어야 합니다. 첫 줄과 마지막 줄이 맞는지, 단을 바꿨을 때 이전 결과가 남지 않는지 확인합니다.

# 반복 범위 읽어보기

## 코드와 실행 결과

파이썬 range(1, 10)은 1부터 9까지를 만듭니다. 끝에 적은 10은 포함되지 않습니다.

```python
dan = 4
for number in range(1, 10):
    print(f"{dan} x {number} = {dan * number}")
```

```output
4 x 1 = 4
4 x 2 = 8
4 x 3 = 12
4 x 4 = 16
4 x 5 = 20
4 x 6 = 24
4 x 7 = 28
4 x 8 = 32
4 x 9 = 36
```

# 목록으로 합계와 평균 구하기

## 코드와 실행 결과

sum은 값을 더하고 len은 개수를 셉니다. 합계와 평균은 다릅니다. 기록이 있을 때만 합계 ÷ 기록 수로 평균을 구합니다.

```python
minutes = [20, 30]
total = sum(minutes)
print(f"합계 {total}분")
if minutes:
    print(f"평균 {total / len(minutes):.1f}분")
else:
    print("평균 기록 없음")
```

```output
합계 50분
평균 25.0분
```

음료 선택 목록과 추가 옵션 체크박스를 둡니다. 처음 음료는 미선택으로 둡니다.

## 계산 규칙 적기

한 잔 가격과 옵션 가격을 더한 뒤 수량을 곱합니다.

## 결과 안내 정하기

음료 이름, 수량, 총액을 함께 보여줍니다. 잘못된 입력은 주문하지 않습니다.

> [!TIP]
> 예상 결과를 먼저 적고 실제 결과와 비교해봅시다.

# 개발 요청 작성하기

## 개발 요청 예시

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
수업용 음료 주문 앱을 만들어줘. 차 2000원, 코코아 2500원, 레모네이드 3000원 중 하나를 선택해. 추가 옵션은 한 잔당 500원이야. 수량은 1~5 정수로 받아 (음료 가격 + 옵션 가격) x 수량을 보여줘. 미선택이나 잘못된 수량은 안내해줘.
```

```response
음료 선택값과 옵션 상태를 읽어 한 잔 가격을 계산하고, 수량을 곱한 총액을 보여주는 구성을 제안할 수 있습니다.
```

# 표는 자료를 일정한 구조로 보여준다

## 개념 이해하기

열은 같은 종류의 정보를 세로로 모읍니다. 과목 열에는 과목 이름을, 시간 열에는 공부한 분 수를 둡니다. 행 하나는 기록 하나입니다.

표는 기록을 보여주는 화면입니다. 화면에서 행만 지우고 계산에 쓰는 기록을 남겨두면 합계가 틀립니다. 삭제는 실제 기록과 화면에 함께 반영해야 합니다.

# 보이는 기록이 저장된 기록은 아니다

## 개념 이해하기

메모리의 기록은 앱이 실행되는 동안 쓰는 값입니다. 다음 실행에서도 쓰려면 기록을 프로젝트 데이터나 파일 등 수업 환경에서 지원하는 저장소에 남겨야 합니다.

실습에서는 교사가 확인한 방식 하나만 사용합니다. 교재의 브라우저 예제는 같은 브라우저의 저장소를 이용합니다. 실제 수업 도구에서는 프로젝트 데이터 저장이나 교사가 준비한 CSV 예제로 바꿀 수 있습니다.
