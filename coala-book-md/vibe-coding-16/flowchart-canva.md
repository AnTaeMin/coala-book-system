# Canva 순서도 제작 인계 · 현재 수정본

원고에 있는 4개 순서도는 의미 구조·노드·연결을 작성했다. 실제 도형 제작은 남아 있다.

- 본문 예상 33쪽: 가족 나이 합의 순서도, 노드 4개.
- 본문 예상 43쪽: 운동 시간 누적 순서도, 노드 5개.
- 본문 예상 53쪽: 수면 시간 조건 순서도, 노드 6개.
- 본문 예상 61쪽: 점수 확인의 반복과 분기, 노드 8개.

전체 노드·연결·YES/NO는 book.md의 각 flowchart 블록을 따른다. source-map.json에는 해당 원본 범위가 있다. 그림은 PNG나 임의 SVG로 대체하지 않는다.

기준: [순서도 제작 규칙](../../skill/coala-canva-textbook/references/flowcharts.md). 선언 MAE7lCxHi8M, 입력 MAGpWHDxa1c, 출력 MAGpWDtQbCc, 처리 MAGpWHT7x4M, 조건 MAGpWETGMb4를 사용한다. 도형·글자·연결선은 각각 편집 가능해야 하며 내부 글꼴은 Hakgyoansim Chilpanjiugae OTF다.

기술 제약에 관한 스킬의 명시 문구: “A person then builds the flowchart in the Canva editor.” 현재 앱은 지정된 라이브러리 요소를 넣을 수 없어 자리를 만든다. 직접 제작·검증하기 전까지 인쇄 최종본이나 순서도 완료라고 표시하지 않는다.
