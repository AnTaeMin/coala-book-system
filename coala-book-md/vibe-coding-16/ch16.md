# 완성 앱과 개발 과정 발표
## 16차시 · 무엇을 만들고 어떻게 확인했는가

### 학습 목표

- 앱의 목적과 핵심 기능을 시연할 수 있다.
- 테스트 결과와 수정 과정을 근거로 설명할 수 있다.
- AI의 도움과 자신의 판단을 구분해 돌아볼 수 있다.

### 오늘의 시작

마지막 시간에는 앱과 개발 과정을 함께 소개합니다. 기능이 작동하는 모습뿐 아니라 어떤 문제를 발견하고 어떻게 수정했는지도 보여줍니다.
:::

:::page{type="concept" id="ch16-concept" layout="basic"}
# 완성은 기획한 기능으로 판단한다

## 개념 이해하기

포트폴리오는 만든 결과와 과정을 보여주는 기록입니다. 앱 이름, 사용자와 문제, 핵심 기능, 실행 화면, 테스트, 수정 사례를 포함합니다.

처음 기획한 기능이 작동하는지 기준으로 설명합니다. 아직 해결하지 못한 문제는 감추지 않고 한계와 다음 개선 계획으로 적습니다.
:::

:::page{type="concept" id="ch16-roles" layout="cards"}
# 핵심 요소 살펴보기

## 결과

사용자의 문제를 해결하는 핵심 기능을 보여줍니다.

## 과정

프롬프트와 수정 요청의 변화를 설명합니다.

## 근거

테스트 입력과 실제 결과로 동작을 증명합니다.
:::

:::page{type="step-process" id="ch16-design"}
# 만들기 전에 정하기

## 발표 구성하기

사용자와 문제, 핵심 기능, 테스트, 수정 사례 순서로 정리합니다.

## 시연 준비하기

정상 입력 한 가지와 잘못된 입력 한 가지를 미리 준비합니다.

## 제출물 확인하기

프로젝트, 실행 화면, 테스트 기록, 성찰 문장을 모읍니다.
:::

:::page{type="practice-opening" id="ch16-practice" practice="016-1" practice-kind="바이브 코딩 실습" platform="수업 실습 환경에서 실행하기"}
# 완성 앱과 개발 과정 발표 실습

2분 안팎으로 앱을 소개해봅시다. 정상 동작과 입력 안내를 직접 시연하고, 수정한 문제 한 가지를 수정 전후로 설명합니다.

> [!TIP]
> 예상 결과를 먼저 적고 실제 결과와 비교해봅시다.
:::

:::page{type="concept" id="ch16-prompt" layout="basic"}
# 개발 요청 작성하기

## 개발 요청 예시

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
내가 적은 앱 개발 기록을 발표용으로 정리하는 것을 도와줘. 사용자와 문제, 실제 구현한 기능, 내가 실행한 테스트 결과, 수정 사례, 남은 한계 순서로 구성해줘. 기록에 없는 기능이나 테스트 성공을 만들어 넣지 말고 빠진 내용은 질문해줘.
```

```response
제공한 기록만 사용하여 발표 흐름을 정리하고, 증거가 없는 부분은 추가 확인 항목으로 남길 수 있습니다.
```
:::

:::page{type="step-process" id="ch16-procedure"}
# 직접 만들고 확인하기

## 최종 테스트하기

기획서의 완료 기준을 다시 확인하고 실제 결과를 적습니다.

## 시연과 발표하기

정상 입력과 오류 입력을 보여주고 가장 중요한 수정 사례를 설명합니다.

## 성찰 남기기

AI가 도운 일, 내가 결정한 일, 다음에 개선할 일을 각각 한 문장으로 적습니다.
:::

# 결과의 증거 남기기

## 확인할 화면

아래는 교재용 브라우저 예제를 실행한 화면입니다. 자기 앱의 입력과 결과를 같은 기준으로 확인하세요.

확인할 자료는 다음과 같습니다.

- 교사 예제의 공부 기록·합계·그래프가 보이는 발표용 실행 화면

:::page{type="comparison" id="ch16-tests"}
# 같은 기준으로 테스트하기

실제 결과와 예상 결과가 같은지 확인하고 통과 여부를 기록합니다.

| 입력 또는 행동 | 예상 결과 |
|---|---|
| 정상 사용 시연 | 핵심 기능과 예상 결과 일치 |
| 잘못된 입력 시연 | 안내와 기존 상태 유지 |
| 최종 테스트 기록 | 입력·예상·실제 결과 포함 |
| 수정 사례 설명 | 수정 전후 근거 포함 |
| 남은 한계 설명 | 실제 미완성 항목 공개 |
:::

:::page{type="concept" id="ch16-debug" layout="basic"}
# 문제를 설명하고 수정하기

## 수정 요청 예시

연습 상황: 발표 자료에 구현하지 않은 기능이 들어갔습니다.

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
발표 초안에 실제로 만들지 않은 저장 기능이 들어갔어. 실행 증거와 개발 기록이 있는 기능만 남겨줘. 미구현 기능은 다음 개선 계획으로 옮기고 테스트 통과도 내 기록 범위에서만 표현해줘.
```

```response
구현 증거가 있는 기능과 다음 계획을 구분하고, 발표의 주장과 테스트 기록이 일치하도록 수정할 수 있습니다.
```
:::
