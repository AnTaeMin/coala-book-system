# 핵심 기능 구현하기
## 14차시 · 작은 기능 하나부터 완성하기

### 학습 목표

- 기획서의 핵심 기능을 순서대로 구현할 수 있다.
- 작동하는 버전을 남기며 기능을 추가할 수 있다.
- 추가한 기능과 기존 기능을 함께 확인할 수 있다.

### 오늘의 시작

기획서를 바탕으로 앱 초안을 만듭니다. 화면 전체를 한 번에 완성하려고 하기보다, 입력 하나가 결과까지 연결되는 작은 기능부터 확인합니다.
:::

:::page{type="concept" id="ch14-concept" layout="basic"}
# 작게 만들고 바로 확인하기

## 개념 이해하기

한 번의 요청에 여러 기능을 넣으면 어디서 문제가 생겼는지 찾기 어렵습니다. 기록 추가가 동작하는지 확인한 뒤 합계를 추가하는 식으로 나누면 수정할 부분을 좁힐 수 있습니다.

버전은 변경 상태를 구분하는 이름입니다. 기능을 확인한 상태를 v1, 새 기능을 추가한 상태를 v2처럼 남기고, 어떤 점이 바뀌었는지 함께 적습니다.
:::

:::page{type="concept" id="ch14-roles" layout="cards"}
# 핵심 요소 살펴보기

## 첫 연결

입력 하나와 결과 하나를 먼저 동작시킵니다.

## 기능 추가

확인한 기능 위에 다음 기능을 더합니다.

## 변경 기록

버전 이름과 변경한 내용을 함께 남깁니다.
:::

:::page{type="step-process" id="ch14-design"}
# 만들기 전에 정하기

## 첫 기능 선택하기

기획서에서 가장 작은 핵심 기능을 고릅니다.

## 작업 요청 나누기

목적, 현재 화면, 이번 기능, 완료 기준을 넣어 요청합니다.

## 작동 버전 남기기

성공한 상태를 저장한 뒤 다음 기능을 추가합니다.
:::

# 핵심 기능 구현하기 실습

13차시 기획서의 핵심 기능을 구현해봅시다. 공통 예시에서는 기록 추가부터 만들고, 목록 표시와 합계 표시를 순서대로 연결합니다.

> [!TIP]
> 예상 결과를 먼저 적고 실제 결과와 비교해봅시다.
:::

:::page{type="concept" id="ch14-prompt" layout="basic"}
# 개발 요청 작성하기

## 개발 요청 예시

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
기획한 공부 기록 앱의 첫 버전을 만들어줘. 과목과 1~600 사이 정수 시간을 받아 기록을 추가하고 목록에 보여줘. 빈 과목이나 잘못된 시간은 안내해줘. 이번에는 저장과 그래프는 넣지 말아줘. 수학 20분과 영어 30분이 두 기록으로 남는지 확인할 방법도 알려줘.
```

```response
기록 추가와 목록 표시를 먼저 구현하고, 두 기록 및 입력 오류 테스트로 첫 버전을 확인할 수 있습니다.
```
:::

:::page{type="step-process" id="ch14-procedure"}
# 직접 만들고 확인하기

## 첫 기능 만들기

자기 기획에 맞게 예시 요청을 수정합니다. 입력과 결과가 연결되는지 확인합니다.

## 다음 기능 더하기

작동 버전을 남긴 뒤 한 기능만 추가합니다. 기존 테스트도 다시 실행합니다.

## 초안 정리하기

현재 작동 기능, 미완성 기능, 다음 수정 항목을 따로 적습니다.
:::

# 결과의 증거 남기기

## 확인할 화면

아래는 교재용 브라우저 예제를 실행한 화면입니다. 자기 앱의 입력과 결과를 같은 기준으로 확인하세요.

확인할 자료는 다음과 같습니다.

- 교사 예제 앱의 첫 핵심 기능이 작동하고 결과가 표시된 실제 화면

:::page{type="comparison" id="ch14-tests"}
# 같은 기준으로 테스트하기

실제 결과와 예상 결과가 같은지 확인하고 통과 여부를 기록합니다.

| 입력 또는 행동 | 예상 결과 |
|---|---|
| 공통 예시: 수학20 추가 | 목록에 1개 표시 |
| 영어30 추가 | 기존 기록 유지, 2개 표시 |
| 빈 과목 입력 | 기록 추가 없음 |
| 합계 기능 추가 후 | 20 + 30 = 50분 |
| 기존 테스트 재실행 | 입력 안내도 정상 유지 |
:::

:::page{type="concept" id="ch14-debug" layout="basic"}
# 문제를 설명하고 수정하기

## 수정 요청 예시

연습 상황: 합계 기능을 추가한 뒤 기록 추가 버튼이 동작하지 않습니다.

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
합계 표시를 추가한 뒤 기록 추가가 안 돼. 마지막으로 작동했던 버전과 비교해서 바뀐 부분을 확인해줘. 기록 추가 기능을 먼저 복원하고, 목록과 합계가 함께 갱신되도록 최소한으로 수정해줘.
```

```response
변경한 부분을 좁혀 기존 기록 추가 동작을 복원한 뒤, 합계 갱신을 다시 연결할 수 있습니다.
```
:::

# 도전과 돌아보기

## 도전 과제

추가 기능 하나의 입력, 동작, 테스트를 적어두되 기본 기능이 완료된 뒤 구현해봅시다.

## 한 문장으로 돌아보기

한 번에 모두 요청할 때보다 작은 기능으로 나누면 어떤 점이 편했나요?

## 개발 기록 남기기

- 이번에 요청한 내용
- 내가 확인한 입력과 결과
- 다음에 바꿀 내용
