# 테스트와 앱 개선
## 15차시 · 문제를 재현하고 수정 확인하기

### 학습 목표

- 오류를 재현할 입력과 행동을 기록할 수 있다.
- 기대 결과와 실제 결과를 구분해 수정 요청을 작성할 수 있다.
- 수정 뒤 기존 기능이 유지되는지 확인할 수 있다.

### 오늘의 시작

내가 쓰기 편한 앱도 다른 사람에게는 어려울 수 있습니다. 짝에게 앱을 사용해보게 하고, 문제를 같은 입력으로 다시 일으켜 수정 요청을 작성합니다.
:::

:::page{type="concept" id="ch15-concept" layout="basic"}
# 오류 보고에는 상황과 증거가 필요하다

## 개념 이해하기

앱이 이상해요만으로는 무엇을 고쳐야 하는지 알기 어렵습니다. 어떤 값을 넣고 어떤 버튼을 눌렀는지, 기대한 결과와 실제 결과가 무엇인지 순서대로 적습니다.

회귀 테스트는 수정 때문에 기존 기능이 망가지지 않았는지 다시 확인하는 활동입니다. 오류가 고쳐진 경우와 원래 잘되던 경우를 함께 실행합니다.
:::

문제 사례와 기존 정상 사례를 함께 실행합니다.

## 변경 범위 정하기

# 테스트와 앱 개선 실습

자기 앱의 테스트 세 가지 이상을 실행해봅시다. 공통 예시에서는 빈 시간 입력, 정상 기록 두 개, 초기화를 확인하고 결과를 기록합니다.

> [!TIP]
> 예상 결과를 먼저 적고 실제 결과와 비교해봅시다.
:::

:::page{type="concept" id="ch15-prompt" layout="basic"}
# 개발 요청 작성하기

## 개발 요청 예시

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
공부 기록 앱에서 시간 칸을 비우고 추가하면 오류가 나. 기대 결과는 시간 입력 안내와 기존 기록 유지야. 현재 수학 20분 기록이 있어. 빈 입력 처리를 수정하고, 수학20·영어30 합계50 기능이 유지되는지 확인할 테스트를 제안해줘.
```

```response
빈 입력을 확인하는 처리를 추가하고 기존 기록 유지, 정상 추가, 합계 계산을 함께 확인하는 테스트를 제안할 수 있습니다.
```
:::

:::page{type="step-process" id="ch15-procedure"}
# 직접 만들고 확인하기

## 문제 기록하기

입력, 누른 버튼, 기대 결과, 실제 결과를 적고 필요하면 화면을 캡처합니다.

## 한 문제 수정하기

작동 버전을 남기고 구체적인 수정 요청을 보냅니다.

## 다시 검증하기

같은 오류 사례와 이전 정상 사례를 실행하고 통과 여부를 적습니다.
:::

:::page{type="concept" id="ch15-result" layout="basic"}
# 결과의 증거 남기기

## 확인할 화면

아래는 교재용 브라우저 예제를 실행한 화면입니다. 자기 앱의 입력과 결과를 같은 기준으로 확인하세요.

확인할 자료는 다음과 같습니다.

- 교사가 빈 입력 오류를 재현한 예제와 입력 검사로 수정한 예제의 화면 비교

이 비교 화면은 빈 입력 처리를 설명하는 최소 예제입니다. 정상 기록 추가와 초기화 테스트는 14차시에서 만든 자기 앱으로 실행합니다.

화면에서 입력과 결과가 함께 보이도록 캡처합니다.

:::page{type="comparison" id="ch15-tests"}
# 같은 기준으로 테스트하기

자기 앱에서 실제 결과와 예상 결과가 같은지 확인하고 통과 여부를 기록합니다. 아래의 정상 추가·초기화는 위 비교 화면의 기능이 아닙니다.

| 입력 또는 행동 | 예상 결과 |
|---|---|
| 시간이 빈 입력 | 입력 안내, 기록 유지 |
| 수학20·영어30 | 합계 50분 |
| 전체 초기화 | 0개 기록, 합계 0분 |
| 초기화 뒤 새 기록 | 정상 추가 |
| 자기 앱의 기준값 | 기획서 예상 결과와 일치 |
:::

:::page{type="concept" id="ch15-debug" layout="basic"}
# 문제를 설명하고 수정하기

## 수정 요청 예시

연습 상황: 입력 안내를 고친 뒤 정상 기록의 합계가 틀립니다.

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
빈 입력 안내는 고쳐졌지만 수학20과 영어30의 합계가 30으로 나와. 두 기록을 보관한 목록과 합계 계산을 확인해줘. 합계는 50이고 빈 입력에서는 기존 기록이 유지되어야 해. 두 경우를 모두 테스트해줘.
```

```response
마지막 입력만 계산하는지 확인하고 전체 기록 기준으로 합계를 구하면서 입력 오류 처리도 다시 검증할 수 있습니다.
```
:::
