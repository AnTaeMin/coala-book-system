# 공부 기록 미니 프로젝트
## 8차시 · 실행 중 기록으로 합계와 평균 구하기

### 학습 목표

- 여러 기록을 목록으로 보관하는 이유를 설명할 수 있다.
- 기록 추가와 합계·평균을 연결할 수 있다.
- 기록이 없거나 입력이 잘못된 경우를 확인할 수 있다.

### 오늘의 시작

3차시의 설계서를 다시 열어봅시다. 과목과 시간을 기록하고, 여러 기록의 합계와 평균을 보여주는 작은 앱으로 연결합니다.
:::

:::page{type="concept" id="ch08-concept" layout="basic"}
# 기록이 쌓이면 계산 결과도 바뀐다

## 개념 이해하기

리스트는 여러 값을 순서대로 담는 자료 구조입니다. 수학 20분, 영어 30분 같은 기록을 따로 보관하면 목록을 보여주고 합계도 다시 계산할 수 있습니다.

평균은 합계를 기록 수로 나눈 값입니다. 기록이 없으면 나눌 기록 수도 0이므로, 계산하기 전에 기록이 있는지 확인해야 합니다.
:::

:::page{type="concept" id="ch08-roles" layout="cards"}
# 핵심 요소 살펴보기

## 목록

과목과 시간을 기록별로 보관합니다.

## 합계

모든 기록의 공부 시간을 더합니다.

## 평균

합계를 기록 수로 나누어 소수 한 자리로 표시합니다.
:::

:::page{type="step-process" id="ch08-design"}
# 만들기 전에 정하기

## 입력 확인하기

과목은 비어 있지 않게, 시간은 1~600 사이의 정수로 받습니다.

## 추가 기능 정하기

올바른 입력만 목록 끝에 추가하고 합계와 평균을 갱신합니다.

## 초기화 정하기

전체 초기화 버튼을 누르면 목록을 비우고 합계 0, 평균은 기록 없음으로 표시합니다.
:::

:::page{type="concept" id="ch08-code" layout="basic"}
# 목록으로 합계와 평균 구하기

## 코드와 실행 결과

sum은 목록의 값을 더하고, len은 값의 개수를 셉니다. 이 예시에는 기록 두 개가 있습니다.

```python
minutes = [20, 30]
total = sum(minutes)
print(f"합계 {total}분")
print(f"평균 {total / len(minutes):.1f}분")
```

```output
합계 50분
평균 25.0분
```
:::

# 공부 기록 미니 프로젝트 실습

공부 기록 앱을 만들어봅시다. 수학 20분과 영어 30분을 추가하여 합계 50분, 평균 25.0분이 되는지 확인합니다. 이번 기록은 앱 실행 중에만 보관합니다.

> [!TIP]
> 예상 결과를 먼저 적고 실제 결과와 비교해봅시다.
:::

:::page{type="concept" id="ch08-prompt" layout="basic"}
# 개발 요청 작성하기

## 개발 요청 예시

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
공부 기록 앱을 만들어줘. 과목과 1~600 사이의 정수 시간을 받아 기록 목록에 추가해줘. 합계와 평균을 소수 한 자리로 보여줘. 기록이 없으면 합계 0분, 평균은 기록 없음으로 표시해줘. 잘못된 입력은 추가하지 말고, 전체 초기화 버튼도 넣어줘.
```

```response
기록 목록을 기준으로 합계와 평균을 갱신하고, 기록이 없는 경우를 별도로 처리하는 구성을 제안할 수 있습니다.
```
:::

:::page{type="step-process" id="ch08-procedure"}
# 직접 만들고 확인하기

## 첫 기록 추가하기

수학 20분을 넣고 목록, 합계, 평균을 확인합니다.

## 두 번째 기록 추가하기

영어 30분을 넣고 두 기록이 유지되는지 확인합니다.

## 오류와 초기화 확인하기

0분과 빈 과목을 넣어 목록이 유지되는지 보고, 전체 초기화도 실행합니다.
:::

:::page{type="comparison" id="ch08-tests"}
# 같은 기준으로 테스트하기

실제 결과와 예상 결과가 같은지 확인하고 통과 여부를 기록합니다.

| 입력 또는 행동 | 예상 결과 |
|---|---|
| 기록 없음 | 합계 0, 평균 기록 없음 |
| 수학 20분 | 합계 20, 평균 20.0 |
| 영어 30분 추가 | 합계 50, 평균 25.0 |
| 0분 또는 빈 과목 | 목록과 합계 유지 |
| 전체 초기화 | 목록 없음, 합계 0 |
:::

# 문제를 설명하고 수정하기

## 수정 요청 예시

연습 상황: 첫 기록이 없을 때 평균 계산에서 오류가 납니다.

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
기록이 없는 상태에서 평균 계산 오류가 나. 기록 수가 0이면 나누지 말고 기록 없음으로 표시해줘. 기록을 추가한 뒤에는 기존 평균 계산을 유지하고 전체 초기화 뒤도 확인해줘.
```
