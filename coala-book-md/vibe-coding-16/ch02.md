# 좋은 개발 프롬프트
## 2차시 · 모호한 요청을 확인 가능한 요청으로

### 학습 목표

- 개발 프롬프트에 필요한 정보를 구분할 수 있다.
- 모호한 요청을 구체적인 요청으로 바꿀 수 있다.
- 두 요청의 결과를 같은 기준으로 비교할 수 있다.

### 오늘의 시작

같은 AI라도 요청에 담긴 정보에 따라 결과가 달라집니다. 이번에는 인사 앱을 예로 들어 목적, 화면, 동작, 예외를 구체적으로 적어봅니다.
:::

:::page{type="concept" id="ch02-concept" layout="basic"}
# 무엇을 만들고 어떻게 확인할까?

## 개념 이해하기

프롬프트는 AI에게 전달하는 요청이나 지시입니다. 예쁜 앱을 만들어줘라는 요청만으로는 어떤 입력과 동작이 필요한지 알기 어렵습니다.

이름을 입력하고 버튼을 누르면 인사말이 나온다처럼 사용자의 행동과 결과를 적으면, 만들어진 앱을 확인할 기준도 생깁니다.
:::

:::page{type="concept" id="ch02-roles" layout="cards"}
# 핵심 요소 살펴보기

## 목적

이름을 넣어 인사하는 앱을 만듭니다.

## 화면

이름 입력창, 인사 버튼, 결과 영역을 둡니다.

## 동작

버튼을 누르면 입력한 이름으로 인사합니다.

## 예외

이름이 비어 있으면 입력을 안내합니다.
:::

:::page{type="step-process" id="ch02-design"}
# 만들기 전에 정하기

## 첫 요청 정하기

인사 앱을 만들어줘라는 짧은 요청을 A로 기록합니다.

## 두 번째 요청 정하기

이름 입력, 버튼 동작, 빈 입력 안내를 넣은 요청을 B로 기록합니다.

## 비교 기준 정하기

입력창 유무, 인사말, 빈 입력 처리 세 가지를 같은 방식으로 확인합니다.
:::

:::page{type="practice-opening" id="ch02-practice" practice="002-1" practice-kind="바이브 코딩 실습" platform="수업 실습 환경에서 실행하기"}
# 좋은 개발 프롬프트 실습

요청 A와 요청 B로 나온 결과를 비교해봅시다. A가 어떤 기능을 만들었는지 미리 단정하지 말고, 실제 화면이나 설명을 보고 기록합니다.

> [!TIP]
> 예상 결과를 먼저 적고 실제 결과와 비교해봅시다.
:::

:::page{type="concept" id="ch02-prompt" layout="basic"}
# 개발 요청 작성하기

## 개발 요청 예시

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
이름을 입력하면 인사하는 앱을 만들어줘. 이름 입력창, 인사하기 버튼, 결과 영역을 둬. 코알라를 넣고 클릭하면 안녕하세요, 코알라!를 보여줘. 빈 입력이나 공백만 있으면 이름을 입력해 주세요를 보여줘. 입력 이름 앞뒤 공백은 제거해줘.
```

```response
입력창과 결과 영역을 만들고, 입력이 비었는지 먼저 확인한 뒤 인사말을 보여주는 구성을 제안할 수 있습니다.
```
:::

:::page{type="step-process" id="ch02-procedure"}
# 직접 만들고 확인하기

## 요청 A 실행하기

짧은 요청으로 얻은 앱이나 제안을 확인하고 기능 세 가지의 유무를 적습니다.

## 요청 B 실행하기

구체적인 요청을 보내고 같은 이름과 빈 입력으로 결과를 확인합니다.

## 근거로 비교하기

더 좋다는 느낌 대신 충족한 기능과 확인한 결과를 적습니다.
:::

확인할 자료는 다음과 같습니다.

- 교사 제작 예제에서 요청 A와 B의 차이를 비교하는 인사 앱 화면

:::page{type="comparison" id="ch02-tests"}
# 같은 기준으로 테스트하기

실제 결과와 예상 결과가 같은지 확인하고 통과 여부를 기록합니다.

| 입력 또는 행동 | 예상 결과 |
|---|---|
| 코알라 입력 | 안녕하세요, 코알라! |
| 빈 입력 | 이름을 입력해 주세요 |
| 공백만 입력 | 이름을 입력해 주세요 |
| 앞뒤 공백이 있는 코알라 | 공백을 뺀 이름으로 인사 |
:::

:::page{type="concept" id="ch02-debug" layout="basic"}
# 문제를 설명하고 수정하기

## 수정 요청 예시

연습 상황: 빈 이름에도 인사말이 출력됩니다.

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
입력이 없는데 안녕하세요, !가 나와. 이름 앞뒤 공백을 제거한 뒤 비어 있으면 이름을 입력해 주세요만 보여줘. 이름이 있는 경우의 인사 기능은 유지해줘.
```

```response
인사말을 만들기 전에 빈 입력을 확인하고, 안내 문구와 정상 인사말을 나누는 방식으로 수정할 수 있습니다.
```
:::
