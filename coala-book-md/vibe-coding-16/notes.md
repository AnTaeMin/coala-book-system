# 교재 제작 지침

## 제작 목적과 기준

- 제목: AI와 함께하는 바이브 코딩
- 대상: 코딩 입문자. 학년·기관 미지정.
- 시간: 16차시, 차시당 50분 가정. 대상과 시간에 따라 조정한다.
- 핵심 경험: 요청, 실행, 결과 확인, 수정의 반복.
- 구성: 4개 단원, 단원마다 4차시. 구체적인 순서는 curriculum.md를 따른다.
- 결과: Canva 앱이 읽는 구조화된 Markdown 원고.
- 학생용 문체: 짧은 설명, 구체적인 예, 직접 해보는 활동.
- 실제 수업 환경은 교사가 확인한 알고플로 Flet 디자이너 또는 준비된 Flet 환경을 사용한다.

## 에이전트에게 사용할 제작 요청

skill/coala-canva-textbook/SKILL.md를 따라 이 notes.md와 curriculum.md를 참고하여
16차시 바이브 코딩 교재를 작성해줘. coala-book-md/ai-math/flet.pdf의 AI,
프롬프트, 입력·처리·출력, 조건·반복, GUI 위젯, 데이터 시각화 내용을 기반으로
승인된 16차시 순서에 맞게 재구성해줘. 입력, 행동, 예상 결과가 보이는 실습과
정상 입력·잘못된 입력·경계값 테스트를 포함해줘. AI 응답 예시는 학습용 작성
예시라고 표시하고 실제 응답이나 실행 결과라고 주장하지 마.
공통 book.md와 ch01.md~ch16.md를 같은 폴더에 두고 assets/를 함께 사용해줘.
모든 Python 예시는 실행하고 실제 출력만 output 블록에 넣어줘.
원고 전체와 차시별 파일을 --layout으로 검증하고 분할 여부를 검토해줘.

## 이미지와 순서도

- 이미지 21개를 준비했다. 기존 파일·출처·비율을 유지하고 원고와 assets/를 함께 전달한다.
- 화면을 AI로 합성하지 않는다. 실습 환경에서 직접 캡처한다.
- screenshot-guide의 캡처는 half를 기본으로 한다. 읽기 어렵다면 넓히고 재검증한다.
- 이미지 자리는 처음에 AI가 추가한 제안이며 현재 모두 파일이 있다. asset-audit.md에서 출처와 준비 상태를 확인한다.
- 조건 분기 순서도는 Canva 네이티브 도형으로 직접 완성한다.
- 원고 작성은 완료되어도 이미지·순서도가 빈 상태인 Canva 교재는 최종 완성본이 아니다.

## 기술·운영 범위

- 로그인, 결제, 외부 API, 로봇, pandas 심화는 필수 과정에 포함하지 않는다.
- 8~10차시 기록은 앱 실행 중 보관이다. 영구 저장은 11차시에서 별도로 다룬다.
- 11차시 교재 예제는 브라우저 저장소를 쓴다. 실제 수업은 프로젝트 데이터 저장 또는 교사 제공 CSV 등 확인된 방식 하나를 택한다.
- 브라우저와 데스크톱의 파일 처리 차이는 교사가 먼저 확인한다.
- 12차시는 환경에 맞는 그래프 예제를 준비한다. 특정 API 이름을 임의로 고정하지 않는다.
- 프로젝트는 핵심 기능 세 가지 이하로 제한하며 매 변경 뒤 기존 기능도 확인한다.
- 실제 사람의 기록 대신 과목명과 예시 시간 등 수업용 자료를 사용한다.

## 참고 자료와 한계

- 직접 확인 가능한 참고 자료: coala-book-md/ai-math/flet.pdf.
- IDE에서 열린 이름의 루트 PDF는 읽기 도구에서 본문이 추출되지 않았다.
- (11).pdf는 작업 폴더에서 발견하지 못했다. 최신 수정본 차이를 반영했다고 주장하지 않는다.
- 테스트 규칙, 가격, 대출 기준, 프로젝트 예시는 이 교재를 위해 새로 작성한 수업용 설정이다.
- institution, 로고, 인쇄 규격을 추측해서 넣지 않는다.
- 원고 canvas는 coala-portrait이며, 실제 인쇄 크기와 축소 비율은 제작 단계에서 확인한다.
- Canva 원본 템플릿과 정확한 시각적 일치는 아직 검증하지 않는다.
