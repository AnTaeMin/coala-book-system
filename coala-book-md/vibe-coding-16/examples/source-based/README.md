# 수업 앱의 Chart 실습 코드 · 2026-10-27

12차시 선·마커 예제 4개와 13차시 막대·산점도 예제 3개입니다. 이 파일들은 생성된 Flet 앱의 시작 처리 또는 버튼 이벤트에 적용하는 **그리기 코드**입니다. 앱에서 이미 만든 cht1·fig_cht1·ax_cht1을 사용합니다.

## 생성된 앱에서 적용하기

1. 디자이너에 Chart를 추가하고 이름을 cht1로 정하여 앱 코드를 생성합니다.
2. 생성된 앱의 차트 생성 부분을 확인합니다. chart_setup.py는 그 부분에 해당하며, flet_charts를 pyplot보다 먼저 가져옵니다.
3. 원하는 예제의 그리기 코드를 앱의 시작 처리 또는 버튼 이벤트 안에 적용합니다. 기존 차트 생성·화면 배치 코드를 유지합니다.
4. 앱을 실행하고 차트의 값·축·마커를 확인합니다. 같은 고정 데이터 예제를 다시 실행하면 이전 그림을 지운 뒤 같은 차트에 다시 그립니다.

.py 파일 7개는 전체 앱이 아닌 이벤트 본문이므로, 단독으로 실행하는 대신 생성된 앱의 차트 문맥에서 사용합니다. chart_setup.py도 화면 배치와 앱 실행 부분을 포함한 전체 앱은 아닙니다. 예제에는 데이터를 그리는 논리만 담습니다. 그림의 배치와 화면 갱신은 수업 도구가 예제 코드 밖에서 처리합니다.

공통 차트 생성 예시: chart_setup.py. 이 파일의 fig_cht1과 ax_cht1은 cht1에 연결된 같은 그림·그리기 영역입니다. 고정 데이터를 다시 그리는 코드 안에서 새 Figure나 새 Chart를 만들지 않습니다. 14차시의 입력 누적 실습은 기존 입력을 유지하는 별도 동작으로 확인합니다.

산점도는 그리기 영역을 초기화한 뒤 축 이름을 X axis·Y axis로 표시합니다.

## 검증 환경 준비

로컬 코드 검사에는 Python 3.10 이상과 requirements.txt의 패키지를 사용합니다.

```powershell
python -m pip install -r requirements.txt
```

저장소 루트의 scripts/check_practice_code.py가 생성된 차트 문맥에서 예제를 검사합니다. 현재 실행 결과와 검증 범위는 ../../code-results.json을 확인합니다.
