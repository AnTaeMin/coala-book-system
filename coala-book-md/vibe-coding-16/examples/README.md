# 교재용 신규 실행 예제

PDF에 없는 이미지의 입력·처리·출력을 실제로 확인하기 위해 제작한 브라우저 예제다.
Flet·알고플로의 UI를 재현한 캡처가 아니며 학생 작품이나 실제 AI 서비스 대화 기록도 아니다.
3·13차시는 교사의 설계 예시다. 15차시는 오류를 의도적으로 넣은 수정 전 예제와 입력 검사를 추가한 수정 후 예제를 비교한다.

## 실행

저장소 루트에서 다음 명령을 실행한다.

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory coala-book-md/vibe-coding-16/examples
```

[예제 열기](http://127.0.0.1:8765/?lesson=4). 아래의 차시 링크로 예제를 선택한다.
종료는 실행한 터미널에서 Ctrl+C다. 외부 서버·계정·API 키는 필요 없다.
캡처용 화면은 주소에 &capture=1을 붙인다. 이 모드는 탐색 메뉴를 숨기고 라벨을 크게 보여준다.

## 캡처에 사용한 입력

| 차시 | 입력·조작 | 확인 결과 |
|---:|---|---|
| 2 | 양쪽 버튼 클릭 | A: 안녕! / B: 안녕하세요, 코알라! |
| 4 | 민수 → 인사하기 | 안녕하세요, 민수! |
| 5 | 2, 3 → 더하기 | 합계 5 |
| 6 | 현재 대출 수 3 → 확인 | 추가 대출 불가 |
| 8 | 수학20, 영어30 추가 | 합계50, 평균25.0 |
| 9 | 코코아, 2잔, 추가 옵션 선택 | 총액6000원 |
| 10 | 수학20, 영어30 → 수학 선택 삭제 | 영어30, 합계30 |
| 11 | 두 기록 저장 → 새로고침 → 불러오기 | 0개에서 2개 복원, 합계50·평균25.0 |
| 12 | 수학20, 영어30, 수학10 → 그래프 보기 | 수학30, 영어30, 원본3행 유지 |
| 14 | 수학20 추가 | 기록1개, 합계20 |
| 15 | 양쪽에 빈 입력 → 각각 추가 | 오류 / 시간 입력 안내·기존20분 유지 |
| 16 | 수학20, 영어30 추가 | 두 기록·합계50·과목별 그래프 |

저장은 이 브라우저의 localStorage를 사용한다. 동일한 브라우저·주소에서 불러와야 한다.
실제 수업 환경의 저장·그래프 API와는 별도로 교사가 구현 방법을 확인한다.
이 예제는 교재 그림을 위한 최소 동작 범위다. 학교 실습 플랫폼의 전체 대체 앱으로 검증한 것은 아니다.

최종 초안에서 음수 덧셈, 빈 목록 평균의 기록 없음 표시, 음료 미선택·수량1~5·이름과 수량 표시, 불러온 평균 재계산을 원고와 맞췄다. 실제 브라우저 검증 20개 사례는 ../example-checks.json에 기록했다.

## 재검토 반영

- 12·16차시: 가로 막대 길이로 과목별 합계를 표시한다. 제목·시간 단위·눈금 범위를 표시하고, 기록이 없으면 안내한다. 큰 값도 화면 폭 안에 비례 표시한다.
- 과목 이름이 constructor·__proto__여도 일반 과목처럼 합산한다. 입력 문자열은 표·그래프에 텍스트로 표시한다.
- 불러오기는 과목 공백, null 항목, 정수가 아닌 시간, 1~600 범위 밖 데이터를 거부하고 현재 기록을 유지한다.
- 15차시 비교 화면은 빈 입력에 대한 수정 전후만 설명한다. 정상 추가·초기화 회귀 테스트는 학생이 만든 앱에서 실행한다.
