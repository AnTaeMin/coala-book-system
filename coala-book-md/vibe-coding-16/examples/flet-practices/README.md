# 실제 Flet 실습 앱과 점검

교재의 입력·위젯·이벤트를 실제 Flet 0.86.0 컨트롤로 만든 실행용 앱입니다. 수업 도구의 현재 생성기와 같은 `flet_charts` 및 `fig_cht1`·`ax_cht1` 구조를 사용합니다.

이 폴더에서 Python 3.10 이상으로 실행합니다.

```powershell
python -m pip install -r requirements.txt
python gallery.py --port 8765
```

브라우저에서 `http://127.0.0.1:8765`를 열고 이전·다음 실습 버튼으로 이동합니다. 각 실습의 입력창과 버튼을 직접 사용할 수 있습니다. `전체 실습 점검`을 누르면 각 실습 화면을 실제 Page에 연결하고 그 버튼에 연결된 이벤트를 실행하여 결과를 검사합니다. `--auto-check` 옵션은 브라우저가 연결된 후 이 검사를 자동으로 실행합니다.

## 들어 있는 앱

| 파일 | 앱 | 확인 항목 |
|---|---:|---|
| basic.py | 13개 | 버튼 색·메시지 창·Field 복사/삭제·누적곱·계산기·Text 누적·구구단·Dropdown·Checkbox·RadioGroup·진행 막대·두 Image·성적표 |
| data.py | 12개 | 입력 차트 3개·학생 자료 2개·걸음 수/거리 저장 1개·조건/반복 알고리즘 6개 |
| plots.py | 7개 | 교재의 Matplotlib 그리기 코드 7개를 실제 cht1에 적용하고 같은 차트에서 반복 갱신 |

학생 자료는 수업 도구가 제공하는 `student_body_100.csv` 100행을 그대로 포함했습니다. 출처와 SHA-256은 data-cases.json에 있습니다. 학교별 학생 수는 고등학교 49명·중학교 51명입니다.

걸음 수·거리 저장 실습은 작업 폴더의 `tmp/flet-practices/walk-project.json`에 실제로 기록하고 초기화한 뒤 복원하여 값과 해시를 비교합니다. 수업 사이트의 계정·내 저장소·제출 기능은 사용하지 않습니다. 두 Image 실습은 제공 이미지 두 개를 사용하므로 외부 이미지 서버에 의존하지 않습니다.

## 실행한 검증

2026-10-27: 실제 브라우저가 연결된 Flet Page에서 32개 모두 통과했습니다. 자동 점검은 실제 이벤트 콜백을 호출하며, 모든 항목을 마우스로 하나씩 클릭했다는 의미는 아닙니다. 산점도 다시 그리기는 별도로 브라우저 버튼을 눌러 표시 갱신을 확인했습니다.

실행 결과는 ../../gui-results.json과 ../../flet-runtime-review.md에 있습니다. 1~3차시의 AI 답변 비교·입력 설계와 16차시의 자유 프로젝트는 정답이 고정된 자동 점검 대상이 아닙니다.

웹 실행 의존성은 requirements.txt의 버전을 사용합니다. 더 최신 FastAPI에서는 Flet 0.86의 웹 서버가 사용하는 인수가 제거되어 실행이 중단되는 것을 확인했으므로 검증한 버전을 고정했습니다.

## sl42 실제 서비스 페이지 확인

sl42의 Chart 생성 코드를 직접 읽어 sl42-generated-chart.py에 보관했습니다. 같은 페이지의 Python GUI 실행 기능에 sl42-runtime-check.py를 적용하고 32개 점검이 모두 통과한 결과를 ../../sl42-runtime-results.json에 기록했습니다. 이 단일 파일은 동일한 예제 소스와 표본·이미지를 브라우저의 가상 파일 영역에 풀어 같은 앱을 실행하는 점검용 묶음입니다. 각 실습 코드는 basic.py·data.py·plots.py에서 읽을 수 있습니다. 로직 예제에서 제외한 배치·화면 갱신 호출은 실행 도구가 별도로 처리합니다.
