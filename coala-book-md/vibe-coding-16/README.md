## Canva 제작

1. 실제 교재 제작용 디자인과 글꼴을 확인합니다. 이 원고의 캔버스는 coala-portrait입니다.
2. 앱의 Choose file에서 book.md 또는 차시 파일을 선택합니다. 파일 선택이 어려우면 원고 붙여넣기에 전체 내용을 넣고 붙여넣은 원고 검사를 누릅니다. 이미지 폴더 선택은 별도로 필요합니다.
3. assets/가 포함된 폴더도 지정합니다. 이미지 21개가 준비되어 있습니다.
4. 생성 후 이미지 삽입 상태를 확인하고 네이티브 순서도 1개를 완성합니다. 표지·목차·단원 구분 페이지는 별도로 추가합니다.
5. 글자 넘침, 캡처 가독성, 페이지 번호, 출력 시 크기를 확인합니다.

검증기는 예상 원고 배치 206장을 계산했습니다. 실제 Canva 사본은 표지·목차를 포함해 209쪽입니다. 원고 순서, 쪽번호, 지면 보정 문구와 초안 PDF를 대조했습니다. 74쪽의 순서도 1개는 작업 자리로 남아 있어 인쇄 최종본으로 표시하지 않습니다.
앱 실습에서 저장과 그래프는 수업 환경에 맞는 교사 준비 예제를 먼저 확인해야 합니다.
참고 PDF는 coala-book-md/ai-math/flet.pdf이며, IDE에 열린 수정본들과의 차이는 반영했다고 주장하지 않습니다.
