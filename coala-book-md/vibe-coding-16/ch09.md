# 선택 메뉴로 주문하기
## 9차시 · 선택한 값으로 결과 계산하기

### 학습 목표

- 하나 선택과 여러 선택의 차이를 설명할 수 있다.
- 선택한 항목과 수량으로 금액을 계산할 수 있다.
- 미선택 상태와 옵션 변경을 테스트할 수 있다.

### 오늘의 시작

직접 글자를 적는 대신 정해진 항목에서 선택할 수 있습니다. 음료 종류와 추가 옵션을 골라 주문 금액을 계산하는 연습 앱을 만듭니다.
:::

:::page{type="concept" id="ch09-concept" layout="basic"}
# 선택 방식은 질문에 맞게 고른다

## 개념 이해하기

드롭다운은 목록에서 하나를 고르는 입력 방식입니다. 체크박스는 옵션을 켜거나 끌 때 사용할 수 있습니다. 음료는 하나를 고르고, 추가 옵션은 따로 선택합니다.

이번 수업의 예시 가격은 차 2,000원, 코코아 2,500원, 레모네이드 3,000원입니다. 추가 옵션은 한 잔당 500원이며 실제 판매 가격을 뜻하지 않습니다.
:::

:::page{type="concept" id="ch09-roles" layout="cards"}
# 핵심 요소 살펴보기

## 음료 선택

세 종류 중 하나를 고릅니다.

## 추가 옵션

한 잔당 500원을 더할지 선택합니다.

## 주문 수량

1~5 사이의 정수를 입력합니다.
:::

:::page{type="step-process" id="ch09-design"}
# 만들기 전에 정하기

## 선택 항목 넣기

음료 선택 목록과 추가 옵션 체크박스를 둡니다. 처음 음료는 미선택으로 둡니다.

## 계산 규칙 적기

한 잔 가격과 옵션 가격을 더한 뒤 수량을 곱합니다.

## 결과 안내 정하기

음료 이름, 수량, 총액을 함께 보여줍니다. 잘못된 입력은 주문하지 않습니다.
:::

:::page{type="practice-opening" id="ch09-practice" practice="009-1" practice-kind="바이브 코딩 실습" platform="수업 실습 환경에서 실행하기"}
# 선택 메뉴로 주문하기 실습

음료 주문 앱을 만들어봅시다. 코코아 두 잔을 선택한 뒤 옵션을 끄고 켜며 총액이 어떻게 달라지는지 확인합니다.

> [!TIP]
> 예상 결과를 먼저 적고 실제 결과와 비교해봅시다.
:::

:::page{type="concept" id="ch09-prompt" layout="basic"}
# 개발 요청 작성하기

## 개발 요청 예시

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
수업용 음료 주문 앱을 만들어줘. 차 2000원, 코코아 2500원, 레모네이드 3000원 중 하나를 선택해. 추가 옵션은 한 잔당 500원이야. 수량은 1~5 정수로 받아 (음료 가격 + 옵션 가격) x 수량을 보여줘. 미선택이나 잘못된 수량은 안내해줘.
```

```response
음료 선택값과 옵션 상태를 읽어 한 잔 가격을 계산하고, 수량을 곱한 총액을 보여주는 구성을 제안할 수 있습니다.
```
:::

:::page{type="step-process" id="ch09-procedure"}
# 직접 만들고 확인하기

## 기본 주문 확인하기

차 한 잔을 옵션 없이 주문하고 2,000원인지 확인합니다.

## 옵션 비교하기

코코아 두 잔을 옵션 없이, 옵션을 넣어 차례로 계산합니다.

## 선택 오류 확인하기

음료 미선택과 수량 0을 넣어 안내가 나오는지 봅니다.
:::

:::page{type="concept" id="ch09-result" layout="basic"}
# 결과의 증거 남기기

## 확인할 화면

아래는 교재용 브라우저 예제를 실행한 화면입니다. 자기 앱의 입력과 결과를 같은 기준으로 확인하세요.

확인할 자료는 다음과 같습니다.

- 코코아 두 잔, 추가 옵션 선택, 총액 6000원이 보이는 주문 화면

화면에서 입력과 결과가 함께 보이도록 캡처합니다.

:::page{type="comparison" id="ch09-tests"}
# 같은 기준으로 테스트하기

실제 결과와 예상 결과가 같은지 확인하고 통과 여부를 기록합니다.

| 입력 또는 행동 | 예상 결과 |
|---|---|
| 차 1잔, 옵션 없음 | 2000원 |
| 코코아 2잔, 옵션 없음 | 5000원 |
| 코코아 2잔, 옵션 있음 | 6000원 |
| 음료 미선택 | 음료 선택 안내 |
| 수량 0 또는 1.5 | 수량 입력 안내 |
:::

:::page{type="concept" id="ch09-debug" layout="basic"}
# 문제를 설명하고 수정하기

## 수정 요청 예시

연습 상황: 코코아 두 잔에 옵션을 넣어도 총액이 5,500원입니다.

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
코코아 두 잔에 옵션을 넣으면 5500원이 나와. 옵션은 주문 전체가 아니라 한 잔당 500원이야. (2500 + 500) x 2 = 6000이 되도록 계산을 수정하고 옵션을 끈 경우도 확인해줘.
```

```response
옵션 가격을 먼저 한 잔 가격에 더하고 수량을 곱하도록 바꾸어, 옵션 유무를 비교할 수 있습니다.
```
:::

:::page{type="practice-checklist" id="ch09-check"}
# 오늘의 완료 확인

- [ ] 가격과 선택값이 올바르게 연결된다.
- [ ] 옵션 가격이 수량만큼 반영된다.
- [ ] 선택을 바꾸어 다시 계산하면 결과도 바뀐다.

> [!KEY_POINT]
> AI의 설명과 실제 실행 결과를 비교한 뒤 완료를 판단합니다.
:::
