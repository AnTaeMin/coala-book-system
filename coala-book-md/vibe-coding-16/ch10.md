# 기록을 표로 보여주기
## 10차시 · 한 기록을 한 행으로 연결하기

### 학습 목표

- 표의 행과 열을 구분할 수 있다.
- 기록 목록을 표의 행으로 나타낼 수 있다.
- 삭제 후 표와 합계가 함께 바뀌는지 확인할 수 있다.

### 오늘의 시작

공부 기록이 많아지면 문장보다 표가 읽기 쉽습니다. 8차시 앱의 기록을 과목과 시간 두 열로 보여주고, 선택한 기록을 지우는 기능을 더합니다.
:::

:::page{type="concept" id="ch10-concept" layout="basic"}
# 표는 자료를 일정한 구조로 보여준다

## 개념 이해하기

열은 같은 종류의 정보를 세로로 모읍니다. 과목 열에는 과목 이름을, 시간 열에는 공부한 분 수를 둡니다. 행 하나는 기록 하나입니다.

표는 기록을 보여주는 화면입니다. 화면에서 행만 지우고 계산에 쓰는 기록을 남겨두면 합계가 틀립니다. 삭제는 실제 기록과 화면에 함께 반영해야 합니다.
:::

:::page{type="concept" id="ch10-roles" layout="cards"}
# 핵심 요소 살펴보기

## 열

과목과 시간(분)이라는 정보 종류입니다.

## 행

수학 20분 같은 기록 한 개입니다.

## 선택과 삭제

선택한 기록 하나를 목록에서 제거합니다.
:::

:::page{type="step-process" id="ch10-design"}
# 만들기 전에 정하기

## 두 열 만들기

과목과 시간(분)을 제목으로 둡니다. 순서와 단위를 분명하게 표시합니다.

## 행 추가 연결하기

올바른 기록을 추가하면 목록과 표에 한 개씩 반영합니다.

## 선택 삭제 연결하기

선택 삭제 버튼으로 한 기록만 지우고 합계와 평균도 다시 계산합니다.
:::

:::page{type="practice-opening" id="ch10-practice" practice="010-1" practice-kind="바이브 코딩 실습" platform="수업 실습 환경에서 실행하기"}
# 기록을 표로 보여주기 실습

공부 기록을 표로 보여주는 앱으로 바꿔봅시다. 수학 20분과 영어 30분을 넣은 뒤 수학 행을 선택하여 삭제합니다.

> [!TIP]
> 예상 결과를 먼저 적고 실제 결과와 비교해봅시다.
:::

:::page{type="concept" id="ch10-prompt" layout="basic"}
# 개발 요청 작성하기

## 개발 요청 예시

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
8차시 공부 기록 앱의 목록을 과목, 시간(분) 두 열의 표로 보여줘. 추가한 기록 하나는 행 하나로 표시해줘. 선택한 행의 기록만 지우는 삭제 버튼을 넣고 합계와 평균도 갱신해줘. 아무 행도 선택하지 않으면 안내하고 기록은 유지해줘.
```

```response
기록 목록에서 표를 만들고, 선택한 기록을 삭제한 뒤 표와 계산 결과를 함께 갱신하는 구성을 제안할 수 있습니다.
```
:::

:::page{type="step-process" id="ch10-procedure"}
# 직접 만들고 확인하기

## 두 행 넣기

수학 20분과 영어 30분을 추가하고 열에 값이 올바르게 들어갔는지 확인합니다.

## 수학 행 삭제하기

수학 기록을 선택하여 삭제하고 영어 30분만 남는지 봅니다.

## 마지막 기록 삭제하기

영어 기록을 삭제합니다. 빈 표와 기록 없음 상태를 확인합니다.
:::

:::page{type="comparison" id="ch10-tests"}
# 같은 기준으로 테스트하기

실제 결과와 예상 결과가 같은지 확인하고 통과 여부를 기록합니다.

| 입력 또는 행동 | 예상 결과 |
|---|---|
| 두 기록 추가 | 표 2행, 합계 50분 |
| 수학 20분 삭제 | 영어 1행, 합계 30분 |
| 아무 행도 선택하지 않음 | 삭제 안내, 기록 유지 |
| 마지막 기록 삭제 | 표 0행, 합계 0분 |
| 같은 과목 두 기록 | 서로 다른 행으로 표시 |
:::

:::page{type="concept" id="ch10-debug" layout="basic"}
# 문제를 설명하고 수정하기

## 수정 요청 예시

연습 상황: 수학 행을 지웠는데 합계가 여전히 50분입니다.

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
수학 20분을 삭제했지만 합계가 50분으로 남아. 화면뿐 아니라 실제 기록 목록에서도 선택한 기록을 삭제하고 합계와 평균을 다시 계산해줘. 영어 30분 한 행만 남는지 확인해줘.
```

```response
삭제 대상이 기록 목록에도 반영되는지 확인하고, 남은 기록으로 표와 합계를 다시 만들 수 있습니다.
```
:::
