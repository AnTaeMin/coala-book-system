# 입력창과 버튼 연결
## 4차시 · 내가 넣은 값을 화면에 보여주기

### 학습 목표

- 입력창, 버튼, 텍스트의 역할을 설명할 수 있다.
- 버튼의 동작을 입력과 결과에 연결할 수 있다.
- 값을 바꾼 뒤 다시 눌러 결과 갱신을 확인할 수 있다.

### 오늘의 시작

버튼만 있던 첫 앱에 이름 입력창을 더해봅시다. 입력한 값을 읽고, 버튼을 눌렀을 때 결과 영역을 바꾸는 과정을 익힙니다.
:::

:::page{type="concept" id="ch04-concept" layout="basic"}
# 화면 요소마다 맡은 일이 있다

## 개념 이해하기

위젯은 입력창이나 버튼처럼 화면을 구성하는 요소입니다. Flet에서는 TextField가 입력을 받고, Button 계열이 클릭을 받으며, Text가 문구를 보여줍니다. 수업 도구의 Field는 입력창을 뜻합니다.

이벤트는 클릭과 같은 사용자 행동입니다. 버튼을 보이게 만드는 것과 클릭했을 때 일을 하게 연결하는 것은 다른 작업입니다.
:::

:::page{type="concept" id="ch04-roles" layout="cards"}
# 핵심 요소 살펴보기

## 이름 입력창

사용자가 적은 이름을 받습니다.

## 인사하기 버튼

클릭하면 이름을 읽는 동작을 시작합니다.

## 결과 텍스트

현재 이름으로 만든 인사말을 보여줍니다.
:::

:::page{type="step-process" id="ch04-design"}
# 만들기 전에 정하기

## 위젯 배치하기

입력창, 버튼, 결과 텍스트를 위에서 아래로 놓습니다.

## 역할 이름 붙이기

사용자가 보는 이름은 이름, 인사하기로 정합니다. 도구가 부여한 위젯 이름도 기록합니다.

## 클릭 동작 적기

이름을 읽고 앞뒤 공백을 제거한 뒤 결과 영역을 바꿉니다.
:::

:::page{type="practice-opening" id="ch04-practice" practice="004-1" practice-kind="바이브 코딩 실습" platform="수업 실습 환경에서 실행하기"}
# 입력창과 버튼 연결 실습

2차시에서 비교했던 인사 앱을 직접 구성해봅시다. 코알라로 인사한 뒤 이름을 민수로 바꿔 다시 클릭하고, 결과가 새 이름으로 갱신되는지 확인합니다.

> [!TIP]
> 예상 결과를 먼저 적고 실제 결과와 비교해봅시다.
:::

:::page{type="concept" id="ch04-prompt" layout="basic"}
# 개발 요청 작성하기

## 개발 요청 예시

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
현재 Flet 실습 환경에서 이름 입력창, 인사하기 버튼, 결과 텍스트를 연결해줘. 코알라를 입력하고 클릭하면 안녕하세요, 코알라!를 보여줘. 이름을 민수로 바꾸고 다시 클릭하면 새 인사말 하나로 바꿔줘. 빈 이름은 안내하고 앞뒤 공백은 제거해줘.
```

```response
버튼의 클릭 동작에서 현재 입력값을 읽고 결과 텍스트를 갱신하도록 구성할 수 있습니다.
```
:::

:::page{type="step-process" id="ch04-procedure"}
# 직접 만들고 확인하기

## 화면 구성하기

세 위젯을 배치하고 현재 위젯 이름을 기록합니다. AI 요청에도 실제 이름을 알려줍니다.

## 이벤트 연결하기

버튼 클릭 시 입력값을 읽고 결과를 바꾸도록 요청합니다.

## 입력 바꾸기

코알라와 민수를 차례로 넣어 결과가 바뀌는지 확인합니다.

:::page{type="comparison" id="ch04-tests"}
# 같은 기준으로 테스트하기

실제 결과와 예상 결과가 같은지 확인하고 통과 여부를 기록합니다.

| 입력 또는 행동 | 예상 결과 |
|---|---|
| 코알라 입력 후 클릭 | 안녕하세요, 코알라! |
| 민수로 변경 후 클릭 | 안녕하세요, 민수! |
| 이름을 지운 뒤 클릭 | 이름을 입력해 주세요 |
| 같은 이름으로 반복 클릭 | 인사말 하나 유지 |
:::

:::page{type="concept" id="ch04-debug" layout="basic"}
# 문제를 설명하고 수정하기

## 수정 요청 예시

연습 상황: 이름을 바꾸어도 첫 번째 인사말만 남습니다.

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
민수로 바꿔 클릭해도 코알라로 인사해. 클릭할 때 현재 입력창 값을 읽는지 확인하고 결과 텍스트를 갱신해줘. 수정한 부분을 설명하고 두 이름으로 다시 테스트하게 해줘.
```

```response
앱 시작 때 읽은 값 대신 클릭 시점의 입력값을 읽는지 확인하고, 결과를 갱신하는 부분을 점검할 수 있습니다.
```
:::
