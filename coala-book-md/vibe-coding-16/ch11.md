# 저장과 불러오기
## 11차시 · 앱을 다시 열어도 기록 유지하기

### 학습 목표

- 실행 중 보관과 다시 불러올 수 있는 저장을 구분할 수 있다.
- 기록을 저장하고 불러오는 절차를 수행할 수 있다.
- 불러오기 뒤 중복과 계산 결과를 확인할 수 있다.

### 오늘의 시작

실행 중에 보이던 기록은 앱을 다시 열면 사라질 수 있습니다. 오늘은 교사가 확인한 저장 방식을 사용해 기록을 저장하고, 빈 상태에서 다시 불러오는 실험을 합니다.
:::

:::page{type="concept" id="ch11-concept" layout="basic"}
# 보이는 기록이 저장된 기록은 아니다

## 개념 이해하기

메모리의 기록은 앱이 실행되는 동안 쓰는 값입니다. 다음 실행에서도 쓰려면 기록을 프로젝트 데이터나 파일 등 수업 환경에서 지원하는 저장소에 남겨야 합니다.

실습에서는 교사가 확인한 방식 하나만 사용합니다. 교재의 브라우저 예제는 같은 브라우저의 저장소를 이용합니다. 실제 수업 도구에서는 프로젝트 데이터 저장이나 교사가 준비한 CSV 예제로 바꿀 수 있습니다.
:::

:::page{type="concept" id="ch11-roles" layout="cards"}
# 핵심 요소 살펴보기

## 저장

현재 기록을 지정한 저장소에 남깁니다.

## 불러오기

저장된 기록으로 현재 목록을 바꿉니다.

## 재계산

불러온 목록에서 합계와 평균을 다시 구합니다.
:::

:::page{type="step-process" id="ch11-design"}
# 만들기 전에 정하기

## 저장 방식 기록하기

프로젝트 데이터 또는 CSV 파일 중 교사가 안내한 하나를 설계서에 적습니다.

## 저장 대상 정하기

과목과 시간만 저장합니다. 합계와 평균은 불러온 뒤 다시 계산합니다.

## 중복 방지 정하기

불러오기는 이어 붙이기가 아니라 현재 기록을 저장된 기록으로 바꾸는 동작으로 정합니다.
:::

:::page{type="practice-opening" id="ch11-practice" practice="011-1" practice-kind="바이브 코딩 실습" platform="수업 실습 환경에서 실행하기"}
# 저장과 불러오기 실습

수학 20분과 영어 30분을 저장해봅시다. 저장 위치를 기록한 뒤 앱을 다시 열어 불러오고, 표 두 행과 합계 50분이 복원되는지 확인합니다.

> [!TIP]
> 예상 결과를 먼저 적고 실제 결과와 비교해봅시다.
:::

:::page{type="concept" id="ch11-prompt" layout="basic"}
# 개발 요청 작성하기

## 개발 요청 예시

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
공부 기록 앱에 교사가 지정한 저장 방식을 적용해줘. 과목과 시간 기록을 저장하고 불러오면 현재 목록을 저장된 목록으로 바꿔줘. 합계와 평균은 다시 계산해줘. 반복 불러오기로 중복하지 말고, 취소나 잘못된 데이터는 기존 기록을 유지하며 안내해줘.
```

```response
지원되는 저장 방식에 맞춰 기록을 저장하고, 불러온 데이터를 검사한 뒤 현재 목록을 교체하는 구성을 제안할 수 있습니다.
```
:::

:::page{type="step-process" id="ch11-procedure"}
# 직접 만들고 확인하기

## 두 기록 저장하기

수학 20분과 영어 30분을 저장하고 저장 위치나 프로젝트 이름을 적습니다.

## 새 실행에서 불러오기

앱을 다시 열어 지정된 자료를 불러옵니다. 표와 합계를 확인합니다.

## 다시 불러오기

같은 자료를 한 번 더 불러옵니다. 행 수가 늘지 않는지 확인합니다.
:::

:::page{type="comparison" id="ch11-tests"}
# 같은 기준으로 테스트하기

실제 결과와 예상 결과가 같은지 확인하고 통과 여부를 기록합니다.

| 입력 또는 행동 | 예상 결과 |
|---|---|
| 두 기록 저장 후 새 실행 | 2행, 합계 50분 복원 |
| 같은 자료 다시 불러오기 | 2행 유지, 중복 없음 |
| 빈 기록 저장·불러오기 | 0행, 평균 기록 없음 |
| 파일 방식에서 선택 취소 | 현재 기록 유지 |
| 형식이 잘못된 자료 | 안내, 현재 기록 유지 |
:::

:::page{type="concept" id="ch11-debug" layout="basic"}
# 문제를 설명하고 수정하기

## 수정 요청 예시

연습 상황: 같은 자료를 두 번 불러오면 기록이 네 개가 됩니다.

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
두 기록을 불러온 뒤 다시 불러오면 네 기록이 돼. 불러온 자료를 기존 목록에 덧붙이지 말고, 검사에 통과한 목록으로 바꿔줘. 합계 50분과 두 행이 유지되는지 확인해줘.
```

```response
데이터를 검사한 뒤 기존 목록을 교체하도록 바꾸고, 반복 불러오기로 행 수와 합계를 확인할 수 있습니다.
```
:::
