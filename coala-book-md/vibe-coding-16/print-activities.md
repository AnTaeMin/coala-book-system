# 지면 보강 활동 · 수정본

이전 199쪽의 실제 좌표·쪽번호 보강 원고를 현재 교재에 그대로 적용하지 않는다. 이번 제작에서는 책의 해당 예시에 맞춰 아래 활동을 적절한 페이지 여백에 넣는다. 본문 글꼴 축소와 상자 넘침으로 지면을 채우지 않는다.

| 예시 | 예측·확인 활동 |
|---|---|
| 가족 나이 합 | 세 나이와 예상 103을 먼저 적고 결과 대조 |
| 운동 누적 | 1·2·3·10일차 합계 따라가기 |
| 수면 분기 | 4.9·5·7.9·8의 분기 예측 |
| 학생 PASS | 입력 수와 결과 수, 80의 경계 확인 |
| Field 복사 | 추가·삭제 전후 값을 두 칸에 기록 |
| 누적곱 | 처음 값 1과 마지막 값 포함 여부 확인 |
| 계산기 | 100/5와 0 나누기 결과 비교 |
| 선택 위젯 | 선택 없음·한 개·여러 개 결과 비교 |
| 성적표 | 입력창과 열 순서의 대응 기록 |
| 차트 | 값 목록·축·개수 대조 |
| 저장 | 저장 전후 행 수와 값 대조 |
| Matplotlib | 코드·마커·축 제목·실제 이미지 대조 |
| Pandas | 행 이름·열 이름·값을 따로 표시 |
| 코코봇 | 입력·명령·관찰 결과와 미실행 구분 |
| 발표 | 수정 전후 같은 입력의 결과 기록 |
