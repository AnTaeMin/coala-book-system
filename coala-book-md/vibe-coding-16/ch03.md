# 입력·처리·출력 설계
## 3차시 · 만들기 전에 동작을 나누기

### 학습 목표

- 입력, 처리, 출력을 구분할 수 있다.
- 핵심 기능과 나중에 추가할 기능을 나눌 수 있다.
- 예시 입력과 예상 결과가 있는 설계서를 작성할 수 있다.

### 오늘의 시작

오늘은 앱을 바로 생성하기보다 설계서를 먼저 만듭니다. 공부 시간을 기록하는 앱이 어떤 값을 받고, 무엇을 계산하며, 무엇을 보여줄지 정합니다.
:::

:::page{type="concept" id="ch03-concept" layout="basic"}
# 앱의 일을 세 부분으로 나누기

## 개념 이해하기

과목과 공부 시간을 받는 일은 입력, 시간을 확인하고 더하는 일은 처리, 합계와 목록을 보여주는 일은 출력입니다. 값을 준비한 뒤 입력 → 처리 → 출력 순서로 설명합니다.

화면을 꾸미기 전에 이 세 부분을 정하면 AI에게도 기능을 분명하게 설명할 수 있습니다. 화면에 있는 요소가 어떤 일을 맡는지 연결해봅시다.
:::

:::page{type="concept" id="ch03-roles" layout="cards"}
# 핵심 요소 살펴보기

## 입력

과목 이름과 공부 시간(분)을 받습니다.

## 처리

시간이 올바른지 확인하고 기록에 더합니다.

## 출력

기록 목록과 총 공부 시간을 보여줍니다.
:::

:::page{type="step-process" id="ch03-design"}
# 만들기 전에 정하기

## 사용자 정하기

자신의 공부 시간을 돌아보고 싶은 학생을 사용자로 정합니다.

## 핵심 기능 정하기

기록 추가, 목록 표시, 합계 표시 세 가지로 범위를 제한합니다.

## 예상 결과 정하기

수학 20분과 영어 30분을 추가하면 기록 두 개와 총 50분이 나와야 합니다.
:::

:::page{type="practice-opening" id="ch03-practice" practice="003-1" practice-kind="바이브 코딩 실습" platform="수업 실습 환경에서 실행하기"}
# 입력·처리·출력 설계 실습

공부 기록 앱의 설계서를 작성해봅시다. 화면 스케치에 입력창 두 개, 추가 버튼, 목록, 합계를 표시하고 각 요소의 역할을 적습니다.

> [!TIP]
> 예상 결과를 먼저 적고 실제 결과와 비교해봅시다.
:::

:::page{type="concept" id="ch03-prompt" layout="basic"}
# 개발 요청 작성하기

## 개발 요청 예시

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
공부 기록 앱의 설계서를 검토해줘. 입력은 과목과 공부 시간(분), 기능은 기록 추가와 목록·합계 표시야. 시간은 0보다 큰 정수만 받게 할 거야. 수학 20분과 영어 30분을 넣으면 합계는 50분이야. 누락된 조건을 질문해주고, 아직 코드는 만들지 말아줘.
```

```response
과목이 비었을 때의 처리와 기록 초기화 여부를 정하면 설계가 더 분명해집니다. 저장 기능은 이번 핵심 범위에 포함되는지도 확인할 수 있습니다.
```
:::

:::page{type="step-process" id="ch03-procedure"}
# 직접 만들고 확인하기

## 세 부분 적기

입력, 처리, 출력 칸을 만들고 각각 필요한 내용을 적습니다.

## 화면 그리기

요소마다 이름과 역할을 적습니다. 버튼에서 결과까지의 행동 순서를 설명합니다.

## 설계 검토하기

짝에게 예시 입력을 읽어주고 어떤 결과가 나올지 말해보게 합니다.
:::

:::page{type="comparison" id="ch03-tests"}
# 같은 기준으로 테스트하기

실제 결과와 예상 결과가 같은지 확인하고 통과 여부를 기록합니다.

| 입력 또는 행동 | 예상 결과 |
|---|---|
| 수학 20분 추가 | 기록 1개, 총 20분 |
| 영어 30분 추가 | 기록 2개, 총 50분 |
| 과목이 빈 기록 | 추가하지 않고 입력 안내 |
| 시간이 문자 또는 0 | 추가하지 않고 양의 정수 안내 |
:::

:::page{type="concept" id="ch03-debug" layout="basic"}
# 문제를 설명하고 수정하기

## 수정 요청 예시

연습 상황: 설계서에 과목이 비었을 때의 동작이 없습니다.

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
설계서에서 과목이 비었을 때의 처리가 빠졌어. 공백을 제거한 과목 이름이 비어 있으면 기록을 추가하지 않는 조건을 넣어줘. 코드 대신 입력·처리·출력과 예시 결과만 수정해줘.
```

```response
입력 검증 단계에 과목 확인을 추가하고, 올바르지 않은 입력일 때 목록과 합계를 유지하는 규칙을 넣을 수 있습니다.
```
:::
