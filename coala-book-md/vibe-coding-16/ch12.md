# 데이터를 그래프로 표현
## 12차시 · 표와 그래프가 같은 값을 보여주는지

### 학습 목표

- 막대그래프의 항목과 값의 의미를 설명할 수 있다.
- 과목별 합계를 그래프로 나타낼 수 있다.
- 표와 그래프의 값이 일치하는지 확인할 수 있다.

### 오늘의 시작

공부 시간을 막대그래프로 보면 과목별 차이를 한눈에 비교할 수 있습니다. 같은 과목의 기록을 모아 합계를 구하고, 표의 값과 그래프를 맞춰봅니다.
:::

:::page{type="concept" id="ch12-concept" layout="basic"}
# 그리기 전에 어떤 값을 보여줄지 정하기

## 개념 이해하기

막대그래프는 항목별 값의 크기를 비교할 때 사용할 수 있습니다. 이 교재의 예제는 가로 막대그래프입니다. 세로 방향으로 과목을 나열하고 가로 방향으로 공부 시간(분)을 나타냅니다. 제목, 단위와 눈금 범위도 표시해야 뜻을 알 수 있습니다.

수학 20분과 수학 10분은 수학 막대 하나의 30분으로 모읍니다. 원래 기록을 보관한 표와 과목별 합계를 보여주는 그래프는 표시하는 단위가 다릅니다.
:::

:::page{type="concept" id="ch12-roles" layout="cards"}
# 핵심 요소 살펴보기

## 기록 표

개별 공부 기록을 그대로 보여줍니다.

## 과목별 합계

같은 과목의 시간을 모아 더합니다.

## 막대그래프

과목별 합계를 막대 길이로 비교합니다.
:::

:::page{type="step-process" id="ch12-design"}
# 만들기 전에 정하기

## 예시 자료 준비하기

수학 20분, 영어 30분, 수학 10분을 입력하거나 불러옵니다.

## 집계 규칙 정하기

같은 과목 이름의 시간을 더합니다. 수학과 영어는 각각 30분입니다.

## 그래프 갱신 정하기

기록을 추가·삭제·불러올 때 그래프도 다시 그리도록 합니다.
:::

:::page{type="practice-opening" id="ch12-practice" practice="012-1" practice-kind="바이브 코딩 실습" platform="수업 실습 환경에서 실행하기"}
# 데이터를 그래프로 표현 실습

공부 기록 앱에 과목별 막대그래프를 추가해봅시다. 수학과 영어의 합계가 같을 때 두 막대의 길이도 같은지 확인합니다.

> [!TIP]
> 예상 결과를 먼저 적고 실제 결과와 비교해봅시다.
:::

:::page{type="concept" id="ch12-prompt" layout="basic"}
# 개발 요청 작성하기

## 개발 요청 예시

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
공부 기록 앱에 과목별 합계 막대그래프를 추가해줘. 수학 20, 영어 30, 수학 10이면 수학과 영어는 각각 30분이야. 과목을 세로로 나열하고 시간을 가로 막대 길이로 나타내줘. 제목과 시간(분), 눈금 범위를 표시하고, 기록 변경 시 갱신해줘. 기록이 없으면 빈 상태를 안내해줘. 수업 환경의 그래프 방식을 사용해줘.
```

```response
기록을 과목별로 합친 값을 그래프에 연결하고, 목록이 바뀔 때마다 집계와 그래프를 갱신하는 구성을 제안할 수 있습니다.
```
:::

:::page{type="step-process" id="ch12-procedure"}
# 직접 만들고 확인하기

## 과목별 합계 구하기

표의 세 기록을 보고 수학과 영어의 합계를 손으로 적습니다.

## 막대와 비교하기

가로축(X)은 시간(분), 세로 방향(Y)은 과목입니다. 막대 길이와 표시 숫자를 과목별 합계와 대조하고 제목·단위·눈금 범위도 확인합니다.

## 기록 변경하기

수학 10분을 삭제하고 수학 막대가 20분으로 바뀌는지 확인합니다.
:::

:::page{type="screenshot-guide" id="ch12-capture"}

## 원래 기록 확인하기

표의 세 기록을 보고 과목별 합계를 계산합니다.

## 그래프 비교하기

그래프의 수학과 영어가 각각 30분인지 확인합니다. 표와 그래프는 같은 세 기록을 사용하며, 과목 순서와 단위도 대조합니다.

:::page{type="comparison" id="ch12-tests"}
# 같은 기준으로 테스트하기

실제 결과와 예상 결과가 같은지 확인하고 통과 여부를 기록합니다.

| 입력 또는 행동 | 예상 결과 |
|---|---|
| 수학20, 영어30, 수학10 | 수학30, 영어30 |
| 수학10 삭제 | 수학20, 영어30 |
| 모든 기록 삭제 | 빈 상태 안내 |
| 자료 다시 불러오기 | 저장 자료 기준 재집계 |
| 시간 단위 확인 | 가로 방향의 시간(분)과 눈금 범위 표시 |
:::

:::page{type="concept" id="ch12-debug" layout="basic"}
# 문제를 설명하고 수정하기

## 수정 요청 예시

연습 상황: 기록을 삭제해도 그래프의 막대가 바뀌지 않습니다.

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
수학 10분을 삭제했는데 수학 막대가 30분으로 남아. 삭제 후 과목별 합계를 다시 계산하고 그래프도 갱신해줘. 표에는 수학 20분과 영어 30분만 남고 그래프도 같은 합계를 보여야 해.
```

```response
기록 변경과 그래프 갱신을 연결하고, 삭제 후 표와 그래프의 값을 함께 확인할 수 있습니다.
```
:::
