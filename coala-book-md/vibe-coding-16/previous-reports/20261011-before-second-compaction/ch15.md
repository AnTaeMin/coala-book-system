# Pandas로 데이터 정리하기

## 15차시 · 개념과 실습

### 학습 목표

- Series와 DataFrame의 차이를 설명할 수 있다.
- 인덱스, 값, 열 이름을 구분할 수 있다.
- 요일별 열과 학생 정보 표를 만들 수 있다.

### 오늘의 시작

# 데이터를 보관하는 형식

데이터 파일의 형식에는 CSV, Excel, JSON 등이 있습니다. 이 차시에서는 딕셔너리와 리스트로 직접 자료를 만들어 실습합니다.

| 형식 | 특징 |
|---|---|
| CSV | 구분자로 항목을 나누는 텍스트 자료 |
| Excel | 시트의 행과 열에 정리한 자료 |

# Series와 DataFrame 비교

입력과 처리 결과를 나란히 비교해봅시다.

| 구분 | Series | DataFrame |

# Series · 딕셔너리와 리스트

one·two·three 딕셔너리와 [2022-01-01, 2.14, song, 1000, True] 리스트로 Series를 만들어봅시다. Series, index, values를 각각 확인합니다.

- [ ] 딕셔너리와 리스트로 Series를 만들었다.

:::page{type="concept" id="ch15-series" layout="basic"}
# 딕셔너리를 Series로 변환

## 예제 코드 실행하기

```python
import pandas as pd

dict_data = {"one": 1, "two": 2, "three": 3}
ser = pd.Series(dict_data)
print(ser)
```

```output
one      1
two      2
three    3
dtype: int64
```
:::

:::page{type="concept" id="ch15-mixed" layout="basic"}
# 리스트를 Series로 변환

## 예제 코드 실행하기

```python
import pandas as pd

list_data = ["2022-01-01", 2.14, "song", 1000, True]
sr = pd.Series(list_data)
print(sr)
print(sr.index)
print(sr.values)
```

```output
0    2022-01-01
1          2.14
2          song
3          1000
4          True
dtype: object
RangeIndex(start=0, stop=5, step=1)
['2022-01-01' 2.14 'song' 1000 True]
```
:::

mon부터 sun까지 딕셔너리를 DataFrame으로 바꿔봅시다. 딕셔너리의 키가 열 이름, 각 리스트가 해당 열의 값이 되는지 확인합니다.

- [ ] DataFrame으로 변환했다.
- [ ] 열 이름과 각 행 값을 확인했다.

:::page{type="concept" id="ch15-dict-frame-code" layout="basic"}
# 요일별 열의 DataFrame

## 예제 코드 실행하기

```python
import pandas as pd

dict_data = {
    "mon": [1, 8, 15, 22],
    "tue": [2, 9, 6, 23],
    "wed": [3, 10, 17, 24],
    "thu": [4, 11, 18, 25],
    "fri": [5, 12, 19, 26],
    "sat": [6, 13, 20, 27],
    "sun": [7, 14, 21, 28],
}
df = pd.DataFrame(dict_data)
print(type(df))
print(df)
```

```output
<class 'pandas.core.frame.DataFrame'>
   mon  tue  wed  thu  fri  sat  sun
0    1    2    3    4    5    6    7
1    8    9   10   11   12   13   14
2   15    6   17   18   19   20   21
3   22   23   24   25   26   27   28
```
:::

# DataFrame · 행·열 이름 지정과 변경

현아 [15, 여, 중2]와 태민 [17, 남, 고1] 자료를 사용해봅시다. 행·열 이름을 확인하고 행은 학생1·학생2, 열은 연령·남녀·학년으로 바꿉니다.

> [!TIP]
> 행 이름은 학생을, 열 이름은 나이·성별·학년 항목을 나타냅니다.

- [ ] 현아·태민의 자료를 사용했다.
- [ ] 행 이름과 열 이름을 구분했다.
- [ ] 학생1·학생2와 연령·남녀·학년으로 변경했다.
:::

:::page{type="concept" id="ch15-dataframe" layout="basic"}
# 현아·태민 자료의 DataFrame

## 예제 코드 실행하기

```python
import pandas as pd

df = pd.DataFrame(
    [[15, "여", "중2"], [17, "남", "고1"]],
    index=["현아", "태민"],
    columns=["나이", "성별", "학년"],
)
print(df)
print(df.index)
print(df.columns)
```

```output
    나이 성별  학년
현아  15  여  중2
태민  17  남  고1
Index(['현아', '태민'], dtype='object')
Index(['나이', '성별', '학년'], dtype='object')
```
:::

# 이름 변경과 값 변경 구분하기

## 인덱스·열 이름 변경

df.index를 학생1·학생2로 바꾸면 행 이름이 달라집니다. df.columns를 연령·남녀·학년으로 바꾸면 열 이름이 달라집니다.

## 데이터는 유지

이름을 바꿔도 15, 17 같은 값이 저절로 바뀌지 않습니다. 라벨 변경과 값 수정을 구분하여 검증합니다.
:::

:::page{type="concept" id="ch15-rename-code" layout="basic"}
# DataFrame 행·열 이름 변경

## 예제 코드 실행하기

```python
import pandas as pd

df = pd.DataFrame(
    [[15, "여", "중2"], [17, "남", "고1"]],
    index=["현아", "태민"],
    columns=["나이", "성별", "학년"],
)
df.index = ["학생1", "학생2"]
df.columns = ["연령", "남녀", "학년"]
print(df)
print(df.index)
print(df.columns)
```

```output
     연령 남녀  학년
학생1  15  여  중2
학생2  17  남  고1
Index(['학생1', '학생2'], dtype='object')
Index(['연령', '남녀', '학년'], dtype='object')
```
:::
