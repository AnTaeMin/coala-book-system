# 자료 활용과 저장·불러오기

## 13차시 · 개념과 실습

### 학습 목표

- 학생 자료의 표시 항목을 선택하고 표·차트로 표현할 수 있다.
- API 자료의 항목을 표·그래프에 연결하고 상위 5개를 표시할 수 있다.
- 표 저장 설정과 프로젝트 저장 후 같은 기록을 다시 확인할 수 있다.

### 오늘의 시작

학생 자료를 불러와 표와 그래프로 살펴봅니다. API는 프로그램이 다른 서비스와 정보를 주고받는 연결 방식입니다. 자료를 가져온 뒤 저장하고 다시 불러오는 과정까지 확인합니다.
:::

:::page{type="practice-opening" id="ch13-practice-data" practice="013-1" practice-kind="자료 활용" platform="알고플로에서 실습하기"}
# 학생 100명 자료 불러와 시각화하기

자료 버튼에서 학생 100명 키·몸무게 자료를 불러와봅시다. 표에 표시할 항목을 고르고 키와 몸무게의 두 열을 산점도의 X·Y로 지정합니다.

> [!TIP]
> 수업에서 제공한 학생 자료를 사용합니다.

- [ ] 학생 100명 자료를 선택했다.
- [ ] 표의 ID·키·몸무게 등 항목을 선택했다.
- [ ] 산점도에 연결할 두 열을 확인했다.
:::

:::page{type="step-process" id="ch13-loaded-data"}
# 저장된 자료 불러오기 순서

## 자료 선택

자료 버튼에서 학생 100명의 키와 몸무게 자료를 선택합니다.

## 표 항목 선택

ID·키·몸무게 또는 ID·성별·키·몸무게 구성을 살펴봅니다.

## 산점도 설정

X축과 Y축에 쓸 열을 직접 확인합니다. 선택한 열의 값과 화면의 축 범위가 맞는지 비교합니다.
:::

# 학교별 학생 수를 막대그래프로 표현

앞에서 불러온 같은 학생 자료를 사용해 학교별 학생 수를 막대그래프로 표시해봅시다. 고등학교와 중학교의 학생 수를 비교합니다.

> [!TIP]
> 앞에서 불러온 자료의 school 열을 사용합니다.

- [ ] 앞의 학생 자료를 그대로 사용했다.
- [ ] 학교 항목별 개수를 집계했다.
- [ ] 고등학교·중학교 막대를 비교했다.
:::

# 자치구별 지하철역 정보 시각화

“서울 교통공사 자치구별지하철역정보” 자료를 사용합니다. 역개수·자치구·해당역(호선)을 tbl1에 표시하고 역 개수가 많은 상위 5개 자치구를 cht1에 나타내봅시다.

> [!TIP]
> 수업에서 확인한 API 주소와 인증 정보를 사용합니다. 직접 가져온 자료의 표·그래프 화면을 저장합니다.

- [ ] 지하철역 자료 구조를 확인했다.
- [ ] 자치구와 역개수를 표·그래프에 연결했다.
- [ ] 상위 5개 자치구를 표시했다.
:::

:::page{type="step-process" id="ch13-api-steps"}
# 지하철역 API 실습 순서

## 자료와 구조 확인

자료에서 역개수·자치구·해당역(호선)의 위치를 확인합니다.

## 위젯 구성

btn1, tbl1, cht1을 구성합니다.

## 데이터 가져오기

수업에서 확인한 API로 데이터를 가져와 표와 막대그래프에 연결합니다.

## 상위 5개 표시

역 개수가 많은 자치구 다섯 개만 선택하여 표시합니다.

# 입력받은 데이터 저장·불러오기

fld1·fld2, tbl1, cht1, 두 버튼으로 화면을 구성해봅시다. 표 저장 설정 후 데이터를 추가하고 프로젝트를 저장합니다. 불러오기에서 같은 기록이 남아 있는지 확인합니다.

> [!TIP]
> 표 저장 설정 전에 행·열 구성을 정합니다.

- [ ] 표 저장 설정을 확인했다.
- [ ] 입력한 표·차트 데이터와 프로젝트를 저장했다.
- [ ] 다시 불러와 같은 기록을 확인했다.
:::

:::page{type="step-process" id="ch13-save-process"}
# 저장·불러오기 확인 순서

## 표 구성과 저장 옵션 확인

먼저 행·열 구성을 정하고 표 저장 옵션을 확인합니다. 저장 설정 후 행·열 변경이 제한되는지 확인합니다.

## 데이터 추가 후 프로젝트 저장

추가한 행 수와 값 목록을 적고 프로젝트 이름을 정해 저장합니다.

## 불러온 뒤 비교

다시 실행하여 표 값과 차트 점을 비교합니다. 수업 도구의 실제 저장 동작을 확인한 뒤 완료를 판단합니다.
:::
