# 입력 데이터를 차트와 저장으로 연결

## 12차시 · 개념과 실습

### 학습 목표

- 선 그래프, 막대그래프, 산점도를 구분할 수 있다.
- 학생 자료와 공공데이터의 표·차트를 확인할 수 있다.
- 프로젝트 저장과 데이터 보관을 구분할 수 있다.

### 오늘의 시작

다섯 값의 선 그래프, 키·몸무게 산점도, 입력값 막대그래프를 만듭니다. 저장된 자료를 다시 열어 같은 값이 남아 있는지도 확인합니다.
:::

:::page{type="comparison" id="ch12-charts"}
# 표현 목적에 맞는 그래프

입력과 처리 결과를 나란히 비교해봅시다.

| 그래프 | 표현할 내용 | 축 확인 |
|---|---|---|
| 선 그래프 | 순서에 따른 값 변화 | 입력 순서와 수치 |
| 막대그래프 | 항목별 값 크기 | 항목과 수치 |
| 산점도 | 두 수치의 짝 | X의 값과 Y의 값 |
:::

:::page{type="practice-opening" id="ch12-practice-1" practice="012-1" practice-kind="시각화 실습" platform="알고플로에서 실습하기"}
# 꺾은선 그래프 만들기

fld1부터 fld5까지 1·2·5·4·5를 입력하고 그래프 그리기 버튼을 눌러봅시다. 초기화 버튼의 역할도 확인합니다.

> [!TIP]
> 그래프의 가로 위치는 입력 순서 0부터 4입니다.

- [ ] 다섯 Field와 Chart를 구성했다.
- [ ] 입력값이 꺾은선으로 표시된다.
- [ ] 초기화 버튼을 확인했다.
:::

# 키·몸무게 산점도 만들기

두 Field에 키와 몸무게를 입력하고 버튼으로 Chart에 점을 추가해봅시다. 170·75, 180·82, 185·89의 세 쌍을 입력하여 점의 위치를 확인합니다.

> [!TIP]
> 현재 값만 표시할지 이전 값과 함께 누적할지 정합니다.

- [ ] 키와 몸무게를 서로 다른 입력창으로 받는다.
- [ ] 입력한 한 쌍이 점 하나로 표시된다.
- [ ] 누적한 세 쌍의 입력값과 점의 위치를 비교했다.

# 입력값 막대그래프 만들기

fld1의 값을 버튼으로 차례로 추가하여 막대그래프로 만들어봅시다. 90·80·70을 입력하여 세 막대의 높이를 비교합니다.

> [!TIP]
> 이전 값을 누적할지 현재 값만 표시할지 정합니다.

- [ ] 입력창·버튼·Chart를 구성했다.
- [ ] 입력한 값을 막대로 표시했다.
- [ ] 90·80·70의 입력값과 세 막대 높이를 비교했다.

# 학생 100명 자료 불러와 시각화하기

자료 버튼에서 학생 100명 키·몸무게 자료를 불러와봅시다. 표에 표시할 항목을 고르고 키와 몸무게의 두 열을 산점도의 X·Y로 지정합니다.

> [!TIP]
> 수업에서 제공한 학생 자료를 사용합니다.

- [ ] 학생 100명 자료를 선택했다.
- [ ] 표의 ID·키·몸무게 등 항목을 선택했다.
- [ ] 산점도에 연결할 두 열을 확인했다.
:::

# 자치구별 지하철역 정보 시각화

“서울 교통공사 자치구별지하철역정보” 자료를 사용합니다. 역개수·자치구·해당역(호선)을 tbl1에 표시하고 역 개수가 많은 상위 5개 자치구를 cht1에 나타내봅시다.

> [!TIP]
> 수업에서 확인한 API 주소와 인증 정보를 사용합니다. 직접 가져온 자료의 표·그래프 화면을 저장합니다.

- [ ] 지하철역 자료 구조를 확인했다.
- [ ] 자치구와 역개수를 표·그래프에 연결했다.
- [ ] 상위 5개 자치구를 표시했다.

# 입력받은 데이터 저장·불러오기

fld1·fld2, tbl1, cht1, 두 버튼으로 화면을 구성해봅시다. 표 저장 설정 후 데이터를 추가하고 프로젝트를 저장합니다. 불러오기에서 같은 기록이 남아 있는지 확인합니다.

> [!TIP]
> 표 저장 설정 전에 행·열 구성을 정합니다.

- [ ] 표 저장 설정을 확인했다.
- [ ] 입력한 표·차트 데이터와 프로젝트를 저장했다.
- [ ] 다시 불러와 같은 기록을 확인했다.
:::

:::page{type="step-process" id="ch12-save-process"}
# 저장·불러오기 확인 순서

## 표 구성과 저장 옵션 확인

먼저 행·열 구성을 정하고 표 저장 옵션을 확인합니다. 저장 설정 후 행·열 변경이 제한되는지 확인합니다.

## 데이터 추가 후 프로젝트 저장

추가한 행 수와 값 목록을 적고 프로젝트 이름을 정해 저장합니다.

## 불러온 뒤 비교

다시 실행하여 표 값과 차트 점을 비교합니다. 수업 도구의 실제 저장 동작을 확인한 뒤 완료를 판단합니다.
:::
