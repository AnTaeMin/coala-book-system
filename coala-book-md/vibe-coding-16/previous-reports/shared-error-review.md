# 공유 오류 검토 · 16차시 교재 반영

검토일: 2026-10-05. 사용자가 제공한 [오류 검토 대화](https://chatgpt.com/share/6ac30ffb-817c-83ee-88a7-0f17049262d1)를 읽고 현재 book.md와 차시별 파일에 해당하는 항목을 대조했다. 사용자가 수정 대상으로 선택한 것은 현재 16차시 교재다. 원본 160쪽 PDF는 수정하지 않았다.

공유 대화는 최초 검토와 수정본 재검토를 모두 포함한다. 이미 고쳐졌다는 항목은 다시 오류라고 단정하지 않는다. 대화의 PDF 페이지 번호는 현재 교재의 페이지 번호가 아니다.

## 기존에 충족한 내용

- 6차시는 실제 법률·건강 기준 대신 교재용 대출 규칙을 명시한다.
- 8차시 합계·평균, 11차시 저장·복원, 12차시 과목별 집계의 입력·예상 결과가 구분되어 있다.
- 12차시 수학 20분·영어 30분·수학 10분은 수학 30분·영어 30분이다. 수학 10분을 삭제하면 수학 20분·영어 30분이다.
- 1·7차시 재사용 캡처 3개와 자체 자료 18개를 구분한다. API 화면을 교재 이미지로 재사용하지 않는다.
- 15차시 비교 화면은 빈 입력 처리 최소 예제라고 표시하며, 정상 추가·초기화는 학생 앱에서 별도로 실행한다.

## 현재 범위에 포함되지 않는 오류

Matplotlib의 Axes 생성·축 제목·show·text, NumPy의 난수·시드, pandas 표 제목, ProgressBar 속성, 코코봇 거리·각도 이벤트는 현재 원고의 코드에 포함되어 있지 않다. 그 코드를 추가하거나 원본 PDF를 수정하지 않았다. 사실 확인 없이 공급자 전용 이벤트 이름을 일반 Python 오류로 바꾸지도 않았다.

## 검증 근거와 제작 상태

최신 구조·예상 배치는 shared-error-validation-full.json과 validation-summary.md, Python 재실행은 code-results.json과 shared-error-checks.json, 이미지 출처는 asset-manifest.json을 참고한다. Canva 사본의 실제 반영 범위와 미완료 항목은 canva-production-status.md에 별도로 기록한다. 원고 검사 통과를 전체 Canva 제작 완료로 해석하지 않는다.

기술 기준: Python [eval](https://docs.python.org/3/library/functions.html#eval)은 입력을 코드로 실행하므로 이 정수 덧셈 과제에 쓰지 않는다. [range](https://docs.python.org/3/library/stdtypes.html#ranges)의 끝값은 제외된다. 공식 문서 확인일 2026-10-05.
