## Canva에 전달할 파일

book.md와 assets 폴더를 함께 전달한다. 이미지 28개가 준비되어 있다. 개별 차시만 만들려면 같은 위치의 chXX.md를 선택한다. 전체와 개별을 중복 생성하지 않는다. 표지·목차는 별도로 구성하고 순서도 4개를 flowchart-canva.md에 따라 완성한다.

삼육보건대 로고를 넣지 않으며 흰 배경·그림자 제거·둥근 사각형 요청 상자를 유지한다. 실제 배치와 인쇄 가독성 검토는 Canva 재생성 후 수행한다. 원본의 작은 캡처는 선명도 한계가 있고, 새 그래프와 표는 1920 × 1200으로 제작했다.
