## 내용의 범위

1-7차시는 AI·질문·문제 분해·순서도·누적·조건·반복 결합, 8-11차시는 책의 Flet 디자이너 실습, 12차시는 차트와 저장, 13차시는 Matplotlib, 14차시는 Pandas, 15차시는 코코봇, 16차시는 책 93-94쪽의 자율 프로젝트 확장이다. 차시별 원본 범위는 curriculum.md와 source-map.json에 있다.

기존 공부 기록·대출·음료 주문의 자체 예시는 현재 원고에서 제외했다. 개발 요청문, 짧은 실행 코드, 테스트 입력, 완료 체크, 발표 활동은 원본을 기반으로 수업용으로 재작성한 내용이다. 실제 AI 대화나 학생 결과물로 소개하지 않는다.

## 코드 확인 근거

실행 환경은 Python 3.10.11, Matplotlib 3.10.9, Pandas 2.3.3, NumPy 2.2.6이다. 23개 코드의 실제 출력과 그래프를 code-results.json에 기록했다. 수업 도구의 최신 Flet 통합 API가 검증되었다는 의미는 아니다.

수정 근거로 확인한 공식 문서: [Matplotlib의 Figure와 Axes](https://matplotlib.org/stable/users/explain/axes/axes_intro.html), [NumPy rand](https://numpy.org/doc/stable/reference/random/generated/numpy.random.rand.html), [Pandas Series](https://pandas.pydata.org/docs/reference/api/pandas.Series.html). 확인일 2026-10-06.
