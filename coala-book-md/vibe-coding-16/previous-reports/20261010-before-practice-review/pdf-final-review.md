## 조판 및 이미지

주요 본문 글꼴은 Wanted Sans, 코드 영문은 Consolas, 순서도는 학교안심 칠판지우개 TTF L이다. 사용 글꼴을 PDF에 포함했다. native Canva의 1587×2245 작업 지면을 A4로 축소할 때의 비율을 기준으로 본문 14pt, 소제목 15pt, 단원 제목 25pt를 적용했다. 본문 행간은 28pt이며 글자 간격을 줄이지 않았다.

흰 바탕과 벡터 글자·도형을 사용했다. 기관 로고와 그림자를 넣지 않았다. 긴 프롬프트는 알약형 타원이 아닌 둥근 사각형에 배치했다. 일부 연속 실습 설명은 제목을 보존하여 한 지면에 합쳤고, 여백에는 해당 예시의 검증 질문과 기록 공간을 마련했다.

원본 캡처 20개와 수정 결과 이미지 8개를 사용했다. 원본 픽셀을 보존하며, 낮은 해상도의 캡처를 새로운 고해상도 화면처럼 소개하지 않는다.

## 검증

원고 파서 검사 통과. 전체 원고의 페이지 ID가 출력에 포함되어 있다. 출력 코드 23개를 원고 코드와 비교하여 내용 차이 0건을 확인했다. 원고 코드의 기존 실제 실행 검증 기록은 code-results.json 및 validation-summary.md를 참고한다.

188쪽을 모두 PNG로 렌더링했다. 모든 쪽의 연락 시트와 주요 쪽의 확대 이미지를 확인했고, 실습 카드·긴 프롬프트·네 순서도·긴 코드·표·원본 캡처·마지막 페이지를 점검했다. Poppler로 실습 및 마지막 수정 순서도를 별도로 렌더링했다.

자동 검사 결과: 페이지 바깥 글자 0, 상자 넘침 0, 원고 ID 누락 0, 목차 오류 0, 대체 문자 0. 주요 글꼴 포함 여부, 이미지 28개, 순서도 4개, 코드 23개와 최종 쪽수를 확인했다. 자세한 조판 정보는 [출력 메타데이터](../../output/pdf/vibe-coding-16-final.json)에 있다.

## 범위

독립 PDF의 배치와 벡터 순서도이며 Canva 원본 네이티브 요소를 그대로 복제한 결과가 아니다. Algoflow 저장, 외부 API, 물리 코코봇의 실제 동작은 이 제작으로 검증하지 않았다. 교재에서는 실행과 미실행 내용을 구분했다.
