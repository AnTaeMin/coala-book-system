# 교사용 운영 안내 · 원본 PDF 기반 16차시

## 준비

1-7차시는 개념과 Python 출력 중심, 8-12차시는 책의 알고플로/Flet 디자이너 환경, 13-14차시는 Matplotlib·NumPy·Pandas가 있는 Python 환경을 사용한다. 15차시는 코코봇 장비가 있어야 실제 이동까지 검증할 수 있다. 장비가 없다면 입력 검증·버튼 매칭·명령 기록을 수행하고 미실행을 명시한다.

원본 도구 화면은 당시 캡처이며 현재 메뉴나 저장 동작을 재현해 확인한 것은 아니다. 수업 전에 프로젝트 생성, 표 저장, 불러오기, 그래프 표시를 해당 계정에서 한 번 실행한다. source-audit.md의 오류 목록을 참고한다. 개인·환자·건강 자료는 가상 입력으로 진행한다.

한 차시에 모두 구현하기보다 설명·예측, 핵심 실습, 실행·수정, 기록으로 구성한다. 수업 시간이 지정되지 않았으므로 다음 구분을 권장한다. 9·10·12·13차시에는 원본의 여러 예시가 포함되어 있어 확장 실습은 선택한다.

## 코드와 실행 이미지

examples/source-based의 23개 Python 파일은 원고와 같은 코드다. Matplotlib의 plt.show는 독립 창 표시용이다. 책의 Flet 앱에 연결하려면 실제 수업 도구에서 Figure 연결과 갱신 코드를 확인한다. 한국어 차트 제목은 해당 환경의 한글 글꼴 설정을 확인한 뒤 사용한다. 현재 차트는 원본 예시의 영어 제목과 축을 사용해 글꼴 누락을 피했다.

## 확인 기록

학생이 입력, 예상 결과, 실제 결과, 수정 요청, 재검증 결과를 남기게 한다. 캡처를 원본에서 가져온 학습 자료와 학생의 실제 결과로 구분한다. AI 답변만으로 통과 표시하지 않는다. 물리 코코봇 미실행과 API 미실행은 점수 대신 미확인 항목으로 기록한다.
