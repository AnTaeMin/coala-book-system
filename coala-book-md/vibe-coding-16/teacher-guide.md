# 교사용 운영 안내

## 수업 전 준비

1. 사용 도구와 Flet 버전을 기록하고 첫 앱을 실제 실행한다.
2. 입력창, 버튼, 텍스트, 선택 위젯, 표를 쓸 수 있는지 확인한다.
3. 학습자의 로그인과 실습 환경을 수업 전에 준비한다. 서비스 이용 조건은 기관에서 확인한다.
4. 11차시 저장·불러오기와 12차시 그래프 예제를 실제 환경에서 먼저 확인한다.
5. 초보자가 새 기능을 만들기 어려울 때 사용할 작동하는 기본 프로젝트를 준비한다.

## 50분 기본 진행

| 활동 | 시간 | 교사의 확인 |
|---|---:|---|
| 도입·이전 결과 복습 | 5분 | 오늘 결과물과 이전 기능 연결 |
| 개념·설계 | 10분 | 입력, 동작, 예상 결과 |
| 실습·AI 요청 | 20분 | 한 기능씩 요청하고 실행 |
| 테스트·수정 | 10분 | 정상·오류·경계값 확인 |
| 개발 기록·정리 | 5분 | 확인한 결과와 남은 문제 |

도전 과제는 기본 활동을 마친 학생의 선택 활동이다. 모든 페이지를 순서대로 읽는 시간은 별도로 넣지 않는다.
예시 응답은 학생이 비교 기준을 이해하도록 만든 집필 예시이며 실제 서비스 응답을 보장하지 않는다.

## 차시별 연결과 지원

- 1차시: 교사 준비 프로젝트를 함께 제공하면 실행 경험부터 확보할 수 있다.
- 2차시: A와 B의 결과가 예상대로 다르지 않아도 실패가 아니다. 실제 결과로 비교한다.
- 3차시: 코드를 생성하지 않고 설계서와 입력·출력 사례를 제출한다.
- 4~7차시: 정상 기능을 먼저 확인하되 원고의 오류 입력 테스트까지 완료한다.
- 8차시: 기록 구조는 과목과 시간으로 통일하고 빈 목록의 평균 계산을 확인한다.
- 9차시: 옵션은 한 잔당 가격이다. 주문 전체에 한 번 더하는 경우와 구별한다.
- 10차시: 화면의 행 삭제와 실제 기록 삭제를 연결한다. 같은 과목 두 기록을 구분하는지도 확인한다.
- 11차시: 저장 방식 하나를 먼저 확정한다. 프로젝트 데이터 저장이 검증되어 있으면 그 방식을 쓴다.
- 11차시: CSV를 쓰면 과목·시간 열과 예시 파일, 정상·잘못된 파일을 교사가 준비한다.
- 11차시: 브라우저에서 로컬 경로를 그대로 읽게 요청하지 않는다. 지원되는 업로드·다운로드나 저장소를 확인한다.
- 12차시: 교사 준비 그래프 템플릿을 사용하여 집계 규칙과 해석에 집중할 수 있다.
- 13차시: 외부 API 등 새로운 기술이 필수인 기획은 배운 범위의 기능으로 줄인다.
- 14차시: 첫 기능이 작동하면 버전을 남기고 다음 기능을 더한다.
- 15차시: 재현 입력, 예상·실제 결과, 수정 후 결과를 함께 기록한다.
- 16차시: 앱 크기나 화려함보다 기획·검증·수정의 근거를 확인한다.

## 공유 오류 검토를 반영한 확인 기준

- 1차시: 사실 확인과 실행 확인을 구분한다. 인증키·비밀번호가 요청이나 제출 화면에 포함되지 않게 주소창과 코드도 확인한다.
- 3차시: 입력 → 처리 → 출력 순서를 확인한다. 계산·검사는 처리이며 같은 출력 단계를 두 번 적지 않는다.
- 5차시: 정수 변환과 덧셈만 사용한다. 입력 문자열을 eval로 실행하지 않는다. 2+3은 이 앱의 정수 입력이 아니므로 안내해야 한다.
- 7차시: 횟수 반복과 조건 반복을 구분한다. 이번 구구단은 range(1, 10)의 아홉 값이며 끝값 10은 제외된다.
- 8차시: 합계와 평균을 구분한다. 기록이 없는 경우를 먼저 처리하며, minutes를 []로 바꿨을 때 합계 0분·평균 기록 없음을 확인한다.
- 12차시: 가로축은 시간(분), 세로 방향은 과목이다. 표의 개별 기록과 그래프의 과목별 합계를 구분하고, 같은 입력으로 숫자·제목·단위·순서·범위를 대조한다.
- 15차시: 코드나 요소 이름을 고쳤으면 해당 화면을 다시 실행·캡처한다. 과거 화면을 수정 후 증거로 쓰지 않는다.
- 목차·차시·실습 번호는 전체 원고와 개별 파일을 대조한다. 실제 Canva 페이지 번호는 생성·분할이 끝난 뒤 확정한다.

공유 대화에서 다룬 Matplotlib·NumPy·pandas·코코봇 코드와 API 호출 화면은 현재 16차시 원고의 필수 내용에 포함되지 않는다. 그 오류를 수정했다고 표시하지 않는다. 수업 도구가 제공하는 객체·이벤트 이름과 일반 Python API는 별도로 확인한다.

검토 출처와 적용 여부는 [shared-error-review.md](shared-error-review.md)에 기록했다. Python의 eval 주의 사항과 range의 끝값 제외 규칙은 [내장 함수 문서](https://docs.python.org/3/library/functions.html#eval)와 [range 문서](https://docs.python.org/3/library/stdtypes.html#ranges)를 대조했다.

## 참고 및 기술 확인 자료

- PDF 참고 범위는 curriculum.md에 기록했다. 신규 예시와 활동을 추가해 재구성했다.
- Flet 입력창·위젯 개념: https://flet.dev/docs/controls/textfield/ , https://flet.dev/docs/controls/
- 표 개념: https://flet.dev/docs/controls/datatable/
- 파일 처리의 환경별 차이: https://flet.dev/docs/services/filepicker/
- 공식 문서 확인 날짜: 2026-10-04. 수업 환경의 API가 최신 문서와 같다고 가정하지 않는다.
- 원고에는 버전에 의존하는 Flet 전체 코드를 넣지 않았다. Python 개념 예시 네 개의 출력은 직접 실행했다.
- 생성형 AI에 요청하는 기능 명세는 설계 목표다. 저장·그래프·앱 코드의 실환경 작동 검증은 수업 전 별도 수행한다.
