# 조건으로 결과 나누기
## 6차시 · 기준값 앞뒤를 확인하기

### 학습 목표

- 조건의 참과 거짓에 따른 동작을 설명할 수 있다.
- 정해진 기준에 따라 안내하는 앱을 만들 수 있다.
- 기준값의 바로 앞과 기준값을 테스트할 수 있다.

### 오늘의 시작

앱은 입력값에 따라 다른 안내를 할 수 있습니다. 현재 빌린 책이 세 권 미만이면 추가 대출 가능, 세 권 이상이면 추가 대출 불가로 안내하는 연습 앱을 만듭니다.
:::

:::page{type="concept" id="ch06-concept" layout="basic"}
# 조건에는 분명한 기준이 필요하다

## 개념 이해하기

책을 많이 빌렸나요라는 질문은 사람마다 다르게 판단할 수 있습니다. 현재 빌린 책이 3권 미만인가라는 조건은 같은 입력에서 같은 판단을 할 수 있습니다.

조건문은 조건에 따라 실행할 일을 나누는 구조입니다. 이번 실습의 세 권 기준은 수업용 규칙이며 실제 도서관 정책을 뜻하지 않습니다.
:::

:::page{type="concept" id="ch06-roles" layout="cards"}
# 핵심 요소 살펴보기

## 참인 경우

현재 대출 수가 3 미만이면 추가 대출 가능입니다.

## 거짓인 경우

현재 대출 수가 3 이상이면 추가 대출 불가입니다.

## 입력 오류

0~10 사이의 정수가 아니면 입력 안내를 합니다.
:::

:::page{type="step-process" id="ch06-design"}
# 만들기 전에 정하기

## 입력 범위 정하기

현재 빌린 책 수를 0~10 사이의 정수로 받습니다.

## 조건 적기

입력이 올바른지 먼저 확인하고, 3 미만인지 판단합니다.

## 안내 정하기

가능, 불가, 입력 안내를 구분하여 보여줍니다.
:::

:::page{type="concept" id="ch06-code" layout="basic"}
# 조건문 읽어보기

## 코드와 실행 결과

비교가 참이면 if 아래를, 거짓이면 else 아래를 실행합니다. 이 예시는 올바른 정수 입력만 다룹니다.

```python
borrowed = 3
if borrowed < 3:
    print("추가 대출 가능")
else:
    print("추가 대출 불가")
```

```output
추가 대출 불가
```
:::

:::page{type="flowchart" id="ch06-branch" height="650"}
# 두 결과로 나뉘는 조건

입력이 0~10 사이의 정수임을 확인한 뒤의 판단을 나타냅니다.

```flowchart
control_structure: if-else
nodes:
  - id: input
    role: input
    text: 현재 대출 수
  - id: check
    role: decision
    text: 3 미만인가?
  - id: yes
    role: output
    text: 추가 대출 가능
  - id: no
    role: output
    text: 추가 대출 불가
connections:
  - from: input
    to: check
  - from: check
    to: yes
    label: YES
  - from: check
    to: no
    label: NO
```
:::

# 조건으로 결과 나누기 실습

현재 대출 수를 입력하면 추가 대출 여부를 알려주는 앱을 만들어봅시다. 2권과 3권을 넣어 경계에서 결과가 바뀌는지 확인합니다.

> [!TIP]
> 예상 결과를 먼저 적고 실제 결과와 비교해봅시다.
:::

:::page{type="concept" id="ch06-prompt" layout="basic"}
# 개발 요청 작성하기

## 개발 요청 예시

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
수업용 도서 대출 안내 앱을 만들어줘. 0~10 사이의 정수를 받아 3 미만이면 추가 대출 가능, 3 이상이면 추가 대출 불가를 보여줘. 빈 입력, 문자, 소수, 범위 밖 값은 0~10 사이의 정수를 입력해 주세요로 안내해줘.
```

```response
입력 범위를 먼저 확인하고, 올바른 값일 때 3 미만 조건으로 두 안내를 나누는 구성을 제안할 수 있습니다.
```
:::

:::page{type="step-process" id="ch06-procedure"}
# 직접 만들고 확인하기

## 기준 확인하기

가능과 불가를 나누는 값이 3인지 설계서에서 확인합니다.

## 경계값 넣기

2와 3을 차례로 넣고 안내가 바뀌는지 적습니다.

## 입력 범위 확인하기

0, 10, -1, 문자도 넣어 분류와 입력 안내를 확인합니다.
:::

:::page{type="comparison" id="ch06-tests"}
# 같은 기준으로 테스트하기

실제 결과와 예상 결과가 같은지 확인하고 통과 여부를 기록합니다.

| 입력 또는 행동 | 예상 결과 |
|---|---|
| 0 또는 2 | 추가 대출 가능 |
| 3 또는 10 | 추가 대출 불가 |
| -1 또는 11 | 범위 입력 안내 |
| 빈 입력 또는 문자 | 정수 입력 안내 |
| 2.5 | 정수 입력 안내 |

:::page{type="concept" id="ch06-debug" layout="basic"}
# 문제를 설명하고 수정하기

## 수정 요청 예시

연습 상황: 3권을 넣어도 추가 대출 가능으로 나옵니다.

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
3권일 때 추가 대출 가능이 나와. 가능 조건은 3 미만이야. 3 이하로 비교하는지 확인하고 수정해줘. 2는 가능, 3은 불가인지 다시 확인하고 입력 범위 검사는 유지해줘.
```

```response
비교 기준이 3 미만인지 확인하고, 2와 3을 넣어 결과가 나뉘는지 검증할 수 있습니다.
```
:::
