# AI와 첫 앱 만들기
## 1차시 · 요청하고 실행하고 확인하기

### 학습 목표

- 바이브 코딩의 기본 과정을 설명할 수 있다.
- 원하는 동작을 짧은 문장으로 요청할 수 있다.
- 앱을 실행하여 요청한 결과와 비교할 수 있다.

### 오늘의 시작

앱을 만드는 첫걸음은 원하는 동작을 말로 설명하는 것입니다. 오늘은 버튼으로 인사 알림창을 여는 앱을 만들고, AI의 설명과 실제 동작이 같은지 확인합니다.
:::

:::page{type="concept" id="ch01-concept" layout="basic"}
# 만들기는 AI와 함께, 확인은 내가

## 개념 이해하기

이 교재에서 바이브 코딩은 자연어로 요구를 설명하고, AI가 제안한 코드나 기능을 실행하며 수정하는 활동입니다. 자연어는 우리가 평소에 쓰는 말입니다.

AI는 빠르게 초안을 만들 수 있지만, 내가 원하는 동작과 다른 결과를 만들 수도 있습니다. 작동하는지 확인하는 일까지 해야 앱 만들기가 끝납니다.
:::

:::page{type="concept" id="ch01-verification" layout="basic"}
# AI 결과를 검증하는 습관

## 자신 있는 설명도 확인하기

AI가 사실이 아닌 내용을 그럴듯하게 답하는 현상을 환각이라고 합니다. 설명의 사실은 공식 자료와 대조하고, 앱의 동작은 직접 실행해 확인합니다.

## 입력할 자료 고르기

수업용 예시 데이터를 사용합니다. 개인정보, 비밀번호, API 인증키는 AI 요청과 제출 화면에 넣지 않습니다. 캡처하기 전에 주소창과 코드도 확인합니다.

## 도움 받은 과정 밝히기

AI가 만든 초안과 내가 수정하고 확인한 부분을 개발 기록에서 구분합니다. 오류를 발견한 과정도 학습 결과입니다.
:::

:::page{type="concept" id="ch01-roles" layout="cards"}
# 핵심 요소 살펴보기

## 요청

화면과 동작을 구체적으로 설명합니다.

## 실행

만들어진 앱을 직접 조작합니다.

## 확인

예상한 결과와 실제 결과를 비교합니다.

## 수정

차이가 난 부분을 한 가지씩 고칩니다.
:::

:::page{type="step-process" id="ch01-design"}
# 만들기 전에 정하기

## 화면 정하기

문구 입력창과 버튼 하나를 둡니다. PDF 예시에서는 버튼 이름이 Button입니다.

## 처음 상태 정하기

처음 입력창에는 안녕하세요를 보여줍니다.

## 동작 정하기

버튼을 누르면 안녕하세요!라는 알림창을 엽니다.
:::

# AI와 첫 앱 만들기 실습

버튼을 누르면 인사 알림창이 열리는 앱을 만들어봅시다. 알림창을 닫은 뒤 다시 눌러 같은 인사말이 나타나는지 확인합니다.

> [!TIP]
> 예상 결과를 먼저 적고 실제 결과와 비교해봅시다.
:::

:::page{type="concept" id="ch01-prompt" layout="basic"}
# 개발 요청 작성하기

## 개발 요청 예시

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
현재 수업 환경에서 인사 알림 앱을 만들어줘. 안녕하세요가 들어 있는 문구 입력창과 Button 버튼을 둬. 클릭하면 안녕하세요!라는 알림창 하나를 열어줘. 알림창을 닫고 다시 눌러도 같은 결과가 나오게 해줘. 실행 방법도 설명해줘.
```

```response
문구 입력창과 버튼을 만들고, 클릭 이벤트에 인사 알림창을 여는 기능을 연결하는 방식으로 구성할 수 있습니다.
```
:::

:::page{type="step-process" id="ch01-procedure"}
# 직접 만들고 확인하기

## 요청 보내기

프롬프트를 입력하고 화면에 필요한 요소가 모두 있는지 읽어봅니다.

## 앱 실행하기

교사가 안내한 수업 환경에서 앱을 실행합니다. 입력창의 처음 문구를 확인합니다.

## 버튼 눌러보기

버튼을 누르고 알림창을 닫습니다. 이 행동을 세 번 더 반복하고 인사말이 같은지 기록합니다.
:::

:::page{type="comparison" id="ch01-tests"}
# 같은 기준으로 테스트하기

실제 결과와 예상 결과가 같은지 확인하고 통과 여부를 기록합니다.

| 입력 또는 행동 | 예상 결과 |
|---|---|
| 실행 직후 | 입력창에 안녕하세요 |
| 한 번 클릭 | 안녕하세요! 알림창 |
| 닫고 세 번 다시 클릭 | 같은 인사 알림 반복 |
| 앱 다시 실행 | 처음 문구와 버튼 표시 |
:::

:::page{type="concept" id="ch01-debug" layout="basic"}
# 문제를 설명하고 수정하기

## 수정 요청 예시

연습 상황: 버튼을 누르면 알림창이 열리지 않고 입력창만 바뀝니다.

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
버튼을 눌러도 알림창이 열리지 않아. 버튼의 클릭 이벤트에 안녕하세요! 알림창을 여는 기능을 연결해줘. 입력창과 버튼 이름은 유지하고, 닫은 뒤 다시 여는 테스트 방법을 알려줘.
```

```response
클릭 이벤트가 연결되었는지 확인하고 알림창을 여는 처리를 수정한 뒤, 닫기와 다시 열기로 확인할 수 있습니다.
```
:::
