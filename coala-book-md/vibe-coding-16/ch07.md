# 반복으로 여러 결과 만들기
## 7차시 · 구구단의 시작과 끝 확인하기

### 학습 목표

- 반복의 시작과 끝을 설명할 수 있다.
- 입력한 단의 구구단을 출력하는 앱을 만들 수 있다.
- 반복 횟수와 결과 갱신을 확인할 수 있다.

### 오늘의 시작

비슷한 계산을 여러 번 적는 대신 반복으로 처리할 수 있습니다. 원하는 단을 입력하면 1부터 9까지 계산해 보여주는 구구단 앱을 만듭니다.
:::

:::page{type="concept" id="ch07-concept" layout="basic"}
# 같은 규칙을 다른 값에 적용하기

## 개념 이해하기

4단은 4에 1부터 9까지 차례로 곱합니다. 반복은 정한 횟수만큼 하거나 조건이 참인 동안 이어갈 수 있습니다. 이번 앱은 아홉 번 반복합니다.

이번 앱의 출력은 아홉 줄이어야 합니다. 첫 줄과 마지막 줄이 맞는지, 단을 바꿨을 때 이전 결과가 남지 않는지 확인합니다.
:::

:::page{type="concept" id="ch07-roles" layout="cards"}
# 핵심 요소 살펴보기

## 반복 값

곱할 수가 1부터 9까지 바뀝니다.

## 반복 내용

입력한 단과 반복 값을 곱합니다.

## 반복 결과

각 계산을 한 줄씩 출력합니다.
:::

:::page{type="step-process" id="ch07-design"}
# 만들기 전에 정하기

## 단 입력 정하기

2~9 사이의 정수 한 개를 받습니다.

## 반복 범위 정하기

곱할 수는 1부터 9까지 포함합니다.

## 출력 갱신 정하기

출력 버튼을 다시 누르면 이전 구구단을 새 결과로 바꿉니다.
:::

:::page{type="concept" id="ch07-code" layout="basic"}
# 반복 범위 읽어보기

## 코드와 실행 결과

파이썬 range(1, 10)은 1부터 9까지를 만듭니다. 끝에 적은 10은 포함되지 않습니다.

```python
dan = 4
for number in range(1, 10):
    print(f"{dan} x {number} = {dan * number}")
```

```output
4 x 1 = 4
4 x 2 = 8
4 x 3 = 12
4 x 4 = 16
4 x 5 = 20
4 x 6 = 24
4 x 7 = 28
4 x 8 = 32
4 x 9 = 36
```
:::

# 반복으로 여러 결과 만들기 실습

2~9 사이의 단을 입력받는 구구단 앱을 만들어봅시다. 4단을 출력한 뒤 5단으로 바꾸어 줄 수와 처음·마지막 줄을 확인합니다.

> [!TIP]
> 예상 결과를 먼저 적고 실제 결과와 비교해봅시다.
:::

:::page{type="concept" id="ch07-prompt" layout="basic"}
# 개발 요청 작성하기

## 개발 요청 예시

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
구구단 앱을 만들어줘. 2~9 사이의 정수 단을 받아 곱할 수 1부터 9까지 아홉 줄로 출력해줘. 4단 마지막 줄은 4 x 9 = 36이야. 다시 출력하면 이전 결과를 새 구구단으로 바꿔줘. 범위 밖, 빈 입력, 문자는 안내해줘.
```

```response
입력한 단을 확인한 뒤 1부터 9까지 반복하여 결과를 만들고, 결과 영역 전체를 바꾸는 구성을 제안할 수 있습니다.
```
:::

:::page{type="step-process" id="ch07-procedure"}
# 직접 만들고 확인하기

## 4단 확인하기

줄 수를 세고 첫 줄과 마지막 줄을 확인합니다.

## 단 바꾸기

5단으로 바꾸고 다시 출력합니다. 4단이 남아 있는지 확인합니다.

## 범위 밖 입력하기

1과 10, 빈 입력을 넣어 올바른 단을 입력하라는 안내를 확인합니다.
:::

:::page{type="comparison" id="ch07-tests"}
# 같은 기준으로 테스트하기

실제 결과와 예상 결과가 같은지 확인하고 통과 여부를 기록합니다.

| 입력 또는 행동 | 예상 결과 |
|---|---|
| 4 입력 | 9줄, 마지막 4 x 9 = 36 |
| 5로 변경 | 9줄, 마지막 5 x 9 = 45 |
| 2 또는 9 입력 | 정상 구구단 9줄 |
| 1 또는 10 입력 | 2~9 입력 안내 |
| 빈 입력 또는 문자 | 정수 입력 안내 |

:::page{type="concept" id="ch07-debug" layout="basic"}
# 문제를 설명하고 수정하기

## 수정 요청 예시

연습 상황: 구구단이 8까지 나오고 마지막 줄이 빠집니다.

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
4단이 4 x 8 = 32까지만 나와. 곱할 수 1부터 9까지 포함되도록 반복 범위를 수정해줘. 결과가 아홉 줄이고 마지막이 4 x 9 = 36인지 확인해줘.
```

```response
반복 범위의 끝값이 포함되는지 확인하고, 아홉 줄과 마지막 계산을 기준으로 수정 결과를 검증할 수 있습니다.
```
:::
