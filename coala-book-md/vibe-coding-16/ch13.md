# 나만의 앱 기획하기
## 13차시 · 누구의 어떤 문제를 해결할까?

### 학습 목표

- 사용자와 해결할 문제를 구체적으로 설명할 수 있다.
- 핵심 기능을 세 가지 이하로 정할 수 있다.
- 완료를 판단할 입력과 예상 결과를 작성할 수 있다.

### 오늘의 시작

이제 배운 기능을 활용해 나만의 앱을 만듭니다. 기능을 많이 넣기보다 한 사용자의 작은 문제를 해결할 핵심 기능을 정합니다.
:::

:::page{type="concept" id="ch13-concept" layout="basic"}
# 아이디어를 사용 장면으로 바꾸기

## 개념 이해하기

좋은 앱이라는 말보다 시험 전 공부 기록을 확인하는 학생을 위한 앱이라는 설명이 구체적입니다. 언제 쓰는지 정하면 꼭 필요한 기능도 고르기 쉬워집니다.

최소 기능 버전은 목적을 확인할 수 있는 가장 작은 작동 버전입니다. 로그인, 외부 API, 결제 같은 추가 기능보다 입력과 결과의 연결을 먼저 완성합니다.
:::

:::page{type="concept" id="ch13-roles" layout="cards"}
# 핵심 요소 살펴보기

## 사용자

누가 어느 상황에서 앱을 쓰는지 적습니다.

## 핵심 기능

이번 수업에서 완성할 기능을 세 가지 이하로 정합니다.

## 완료 기준

구체적인 입력과 예상 결과로 성공을 판단합니다.
:::

:::page{type="step-process" id="ch13-design"}
# 만들기 전에 정하기

## 문제 문장 쓰기

누가, 언제, 무엇이 불편한지를 한 문장으로 적습니다.

## 기능 줄이기

공부 기록, 준비물 확인, 간단한 주문 등 배운 범위에서 기능을 고릅니다.

## 테스트 먼저 쓰기

정상 입력, 빈 입력, 기준값을 포함한 테스트 세 가지 이상을 정합니다.
:::

:::page{type="practice-opening" id="ch13-practice" practice="013-1" practice-kind="바이브 코딩 실습" platform="수업 실습 환경에서 실행하기"}
# 나만의 앱 기획하기 실습

내 앱의 기획서를 작성해봅시다. 아이디어가 떠오르지 않으면 공부 기록 앱을 선택하고, 기록 추가·목록 표시·합계 표시를 핵심 기능으로 정합니다.

> [!TIP]
> 예상 결과를 먼저 적고 실제 결과와 비교해봅시다.
:::

:::page{type="concept" id="ch13-prompt" layout="basic"}
# 개발 요청 작성하기

## 개발 요청 예시

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
내 앱 기획을 검토해줘. 사용자와 문제, 핵심 기능 세 가지, 입력·처리·출력, 테스트 기준을 차례로 정리하고 싶어. 아직 코드는 만들지 말고 내가 적지 않은 부분을 먼저 질문해줘. 수업 시간에 끝내기 어려운 기능은 별도 확장 목록으로 분리해줘.
```

```response
사용 상황과 완료 기준을 먼저 확인하고, 필수 기능과 확장 기능을 나누는 방식으로 기획을 도울 수 있습니다.
```
:::

:::page{type="step-process" id="ch13-procedure"}
# 직접 만들고 확인하기

## 초안 작성하기

앱 이름, 사용자, 문제, 기능 세 가지를 적습니다.

## 짝에게 검토받기

짝이 설계서를 보고 예시 입력의 결과를 예상할 수 있는지 확인합니다.

## 범위 확정하기

핵심 기능과 다음에 만들 기능을 구분하고 교사와 작업 범위를 확인합니다.
:::

:::page{type="comparison" id="ch13-tests"}
# 같은 기준으로 테스트하기

실제 결과와 예상 결과가 같은지 확인하고 통과 여부를 기록합니다.

| 입력 또는 행동 | 예상 결과 |
|---|---|
| 사용자와 문제 설명 | 구체적 사용 상황 1개 |
| 핵심 기능 확인 | 세 가지 이하 |
| 입력과 출력 확인 | 각 기능의 입출력 명시 |
| 테스트 확인 | 예상 결과 있는 사례 3개 이상 |
| 완료 가능성 확인 | 배운 기능으로 구현 가능 |
:::

:::page{type="concept" id="ch13-debug" layout="basic"}
# 문제를 설명하고 수정하기

## 수정 요청 예시

연습 상황: 기획서에 만들고 싶은 기능이 열 개나 있습니다.

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
기획 기능이 열 개라 수업 안에 완성하기 어려워. 앱 목적에 꼭 필요한 기능 세 가지를 고를 수 있게 우선순위를 질문해줘. 나머지는 다음 버전 목록으로 옮기고 핵심 기능의 완료 기준을 적게 해줘.
```

```response
문제를 해결하는 데 필요한 기능부터 고르고, 선택한 기능마다 확인 가능한 완료 기준을 정할 수 있습니다.
```
:::
