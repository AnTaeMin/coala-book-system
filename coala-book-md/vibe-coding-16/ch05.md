# 변수와 숫자 계산
## 5차시 · 입력한 두 수로 덧셈하기

### 학습 목표

- 변수의 역할과 문자·숫자의 차이를 설명할 수 있다.
- 숫자 입력으로 덧셈 앱을 만들 수 있다.
- 잘못된 입력에서 계산하지 않도록 요청할 수 있다.

### 오늘의 시작

입력창에 적힌 숫자는 계산하기 전에 숫자로 해석해야 합니다. 이번에는 두 수를 더하는 계산기를 만들고, 빈 입력과 문자를 넣었을 때도 확인합니다.
:::

:::page{type="concept" id="ch05-concept" layout="basic"}
# 문자를 잇는 것과 수를 더하는 것

## 개념 이해하기

변수는 값을 보관하고 이름으로 다시 사용하는 방법입니다. 입력창에 적은 2와 3을 문자로 이어 붙이면 23이지만, 숫자로 바꿔 더하면 5입니다.

이번 앱은 부호가 있는 정수 두 개를 받습니다. 빈 입력, 소수, 숫자가 아닌 문자는 계산하지 않고 정수를 입력하라는 안내를 보여줍니다.
:::

:::page{type="concept" id="ch05-roles" layout="cards"}
# 핵심 요소 살펴보기

## 입력값

사용자가 적은 내용을 읽습니다.

## 숫자 변환

계산할 수 있는 정수인지 확인합니다.

## 계산과 출력

두 정수를 더하고 합계를 보여줍니다.
:::

:::page{type="step-process" id="ch05-design"}
# 만들기 전에 정하기

## 입력과 버튼 정하기

첫 번째 수, 두 번째 수 입력창과 더하기 버튼을 둡니다.

## 계산 규칙 정하기

두 입력을 각각 정수로 바꾼 뒤 + 연산으로 더합니다. 입력 문자열을 코드로 실행하는 eval은 사용하지 않습니다.

## 실패 결과 정하기

입력이 올바르지 않으면 이전 숫자 결과 대신 정수 입력 안내를 보여줍니다.
:::

:::page{type="concept" id="ch05-code" layout="basic"}
# 같은 입력, 다른 계산

## 코드와 실행 결과

첫 줄은 문자를 이어 붙입니다. 두 번째 줄은 정수로 바꾼 값을 더합니다. 입력이 올바른 정수일 때의 짧은 예시입니다.

```python
first = "2"
second = "3"
print(first + second)
print(int(first) + int(second))
```

```output
23
5
```
:::

# 변수와 숫자 계산 실습

두 정수를 더하는 앱을 만들어봅시다. 2와 3의 합이 5인지 먼저 확인하고, 0과 음수도 넣어봅니다.

> [!TIP]
> 예상 결과를 먼저 적고 실제 결과와 비교해봅시다.
:::

:::page{type="concept" id="ch05-prompt" layout="basic"}
# 개발 요청 작성하기

## 개발 요청 예시

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
두 정수 덧셈 앱을 만들어줘. 입력창 두 개, 더하기 버튼, 결과 텍스트를 둬. 입력을 정수로 바꿔 + 연산으로 더하고 eval은 쓰지 마. 2와 3은 5, -2와 3은 1이 나와야 해. 빈 입력, 문자, 소수, 2+3 같은 수식은 계산하지 말고 정수 입력을 안내해줘. 이전 결과가 잘못 남지 않게 해줘.
```

```response
두 입력을 정수로 변환할 수 있는지 확인한 뒤 더하고, 변환할 수 없을 때는 안내 문구를 보여주는 구성을 제안할 수 있습니다.
```
:::

:::page{type="step-process" id="ch05-procedure"}
# 직접 만들고 확인하기

## 기본 계산하기

2와 3을 넣고 결과를 기록합니다. 내가 계산한 값과 비교합니다.

## 다른 정수 넣기

0과 음수를 넣고 기대한 합계가 나오는지 확인합니다.

## 입력 오류 확인하기

한 칸을 비우거나 문자를 넣습니다. 오류 안내 뒤 정상 입력도 다시 확인합니다.
:::

# 문제를 설명하고 수정하기

## 수정 요청 예시

연습 상황: 2와 3을 넣었는데 23이 나옵니다.

아래 답변은 학습을 위해 작성한 예시입니다. 실제 AI 응답과 앱 동작은 직접 확인하세요.

```prompt
2와 3을 넣으면 합계 5 대신 23이 나와. 두 입력을 문자로 이어 붙이는지 확인하고 정수로 변환한 뒤 더하도록 수정해줘. 빈 입력과 문자 입력의 안내는 유지해줘.
```

