# 실습 2 · 나란한 막대그래프

## 생성된 차트에 적용하기

```python
ax_cht1.clear()
topics = ["one", "two", "three", "four", "five"]
value_a = [35, 80, 84, 83, 50]
value_b = [73, 80, 77, 40, 86]

def create_x(t, w, n, d):
    return [t * x + w * n for x in range(d)]

value_a_x = create_x(2, 0.8, 1, 5)
value_b_x = create_x(2, 0.8, 2, 5)
ax_cht1.bar(value_a_x, value_a)
ax_cht1.bar(value_b_x, value_b)
middle_x = [(a + b) / 2
            for a, b in zip(value_a_x, value_b_x)]
ax_cht1.set_xticks(middle_x)
ax_cht1.set_xticklabels(topics)
```

# 실습 3 · 산점도

## 생성된 차트에 적용하기

```python
import numpy as np
from matplotlib import font_manager

fonts = {f.name for f in
         font_manager.fontManager.ttflist}
families = ("Malgun Gothic", "AppleGothic",
            "Noto Sans CJK KR", "Noto Sans KR",
            "NanumGothic", "Wanted Sans")
font_name = next((f for f in families
                  if f in fonts), None)
if font_name:
    plt.rcParams["font.family"] = font_name
plt.rcParams["axes.unicode_minus"] = False

ax_cht1.clear()
np.random.seed(20211206)
x = np.arange(1.1, 100.0, 5.0)
y = x * 1.5 + np.random.rand(20) * 50
ax_cht1.scatter(x, y, c="red", alpha=0.5, label="random")
ax_cht1.set_xlabel("X축 제목" if font_name else "X axis")
ax_cht1.set_ylabel("Y축 제목" if font_name else "Y axis")
ax_cht1.legend(loc="upper left")
ax_cht1.set_title("random")
```

# 산점도의 데이터와 축 설정

## 난수 시드 확인

seed는 난수 생성기의 상태를 정합니다. 같은 시드와 생성 순서를 사용하면 같은 난수를 얻습니다. 산점도의 X·Y 값은 코드에서 생성한 연습용 데이터입니다.

## 축 이름과 범례

ax_cht1의 set_xlabel, set_ylabel로 축 이름을 설정합니다. 예제는 설치된 한글 글꼴을 고른 뒤 clear로 그리기 영역을 초기화합니다. 해당 글꼴이 없으면 X axis·Y axis로 표시합니다. 한글을 보려면 families의 글꼴 중 하나를 설치한 뒤 다시 실행합니다. random 범례와 빨간 점을 비교합니다.
