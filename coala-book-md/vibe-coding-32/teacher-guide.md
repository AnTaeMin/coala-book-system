# 32차시 교사용 운영 안내 · 2026-11-03

수업 주제는 기존 명칭 뒤에 1 또는 2를 붙이고, 실제 수업 번호는 1~32차시로 매깁니다. 각 2부는 앞 1부의 개념을 바탕으로 이어서 진행하고, 본문에서 지정한 프로젝트와 데이터를 사용합니다.

1~4차시는 AI와 질문, 5~14차시는 알고리즘, 15~32차시는 GUI·앱 제작입니다. 23~24차시 선·마커, 25~26차시 막대·산점도, 27~28차시 입력 Chart, 29~30차시 자료·저장, 31~32차시 프로젝트 순서입니다.

차시마다 도입의 학습 목표를 확인한 뒤 본문의 입력·처리·출력과 실제 실행 결과를 비교합니다. 1부 끝에서는 수행한 내용을 정리하고 프로젝트를 보존합니다. 2부에서는 앞 차시의 개념을 확인한 뒤 본문의 예제를 진행합니다. 단일 실습을 두 차시에 걸쳐 진행하는 주제도 있으므로 실습 개수와 차시 수는 다릅니다.

실습 안내 번호는 새 차시에 맞춰 다시 매겼습니다. 본문 페이지 ID와 이미지 경로는 출처 추적을 위해 유지했고, 대응 관계는 [session-split.json](session-split.json), 세부 수업 구성은 [curriculum.md](curriculum.md)에 있습니다.

기존 2차시의 질문 비교 실습은 새 3차시에서 프롬프트 비교 바로 뒤에 배치했습니다. 그 밖의 본문 순서는 유지합니다. 코드·순서도·결과 화면은 기존 자료를 사용합니다. 재검토에서 참고 화면의 차이를 명시하고, 표 셀 수정의 위젯·이벤트와 AI 도움 구분 발표 안내를 보완했습니다. 실행 예제와 기존 검증 기록은 [16차시 원본 안내](../vibe-coding-16/README.md)를 참고합니다.
