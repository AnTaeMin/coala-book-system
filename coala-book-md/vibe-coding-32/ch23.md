# 그릴 판과 그리는 영역

## cht1과 Figure·Axes

디자이너에서 Chart를 추가하고 이름을 cht1로 정하면, 생성된 앱 코드에 다음 구조가 들어갑니다. fig_cht1은 전체 그림, ax_cht1은 데이터를 그리는 영역이며, cht1은 이 그림을 보여 주는 위젯입니다.

## 처음 한 번 생성되는 차트

```python
import flet_charts as fch
import matplotlib.pyplot as plt

fig_cht1, ax_cht1 = plt.subplots()
cht1 = fch.MatplotlibChart(
    expand=True, figure=fig_cht1)
```

::image{src="assets/ch12/chart-binding.png" alt="cht1에 연결된 빈 Figure와 Axes" ratio="4:3" width="half" role="result" caption="처음 생성된 빈 그래프. 다음 예제에서 같은 영역에 데이터를 그립니다."}

이 코드는 앱을 구성할 때 한 번 실행됩니다. 생성된 앱의 배치 코드가 cht1을 화면에 연결합니다. 이미 생성된 차트에서는 이 부분을 다시 만들지 않습니다.

## 기존 차트에 그리기

이어지는 예제는 같은 앱에서 ax_cht1에 그림을 그리는 부분입니다. 생성된 앱의 시작 처리나 버튼 이벤트 안에 적용합니다. 고정 데이터를 다시 그릴 때는 clear로 이전 그림을 지우고 새 데이터를 그립니다. 그림의 배치와 화면 갱신은 수업 도구가 그리기 코드 밖에서 처리합니다. 독립 실행용 전체 프로그램이 아니므로 생성된 앱의 나머지 코드를 유지합니다.
:::

# Matplotlib 실습 1 · 배열 한 개

[1, 2, 3, 4, 5] 배열을 선으로 그려봅시다. 하나의 배열을 전달했을 때 X축이 0부터 4까지의 위치가 되는지 확인합니다.

> [!TIP]
> Axes에 plot을 호출하여 데이터를 그립니다.

- [ ] [1, 2, 3, 4, 5] 배열을 사용했다.
- [ ] 배열 하나를 plot에 전달했다.
- [ ] X 위치 0부터 4를 확인했다.
:::

# Matplotlib 실습 2 · X·Y 배열

a = [15, 25, 35, 45, 55], b = [5, 10, 15, 20, 25]를 X와 Y로 지정해봅시다. 두 배열의 같은 위치 값이 한 점의 좌표가 됩니다.

> [!TIP]
> 두 배열의 길이와 값의 짝을 확인합니다.

- [ ] a와 b 배열을 지정했다.
- [ ] a는 X, b는 Y로 연결했다.
- [ ] 다섯 점의 위치를 X·Y 값과 비교했다.
:::

:::page{type="concept" id="ch12-two-arrays" layout="basic"}
# 실습 2 · X·Y 배열 지정

ax_cht1.plot(a, b)

# Matplotlib 실습 3 · 표시 범위

X는 [1, 2, 3, 4, 5], Y는 [5, 10, 15, 20, 25]로 정합니다. b-+ 모양과 axis([0, 10, 0, 25])를 적용해봅시다.

> [!TIP]
> 값을 바꾸는 것과 표시 범위를 바꾸는 것을 구분합니다.

- [ ] 지정한 X·Y 값을 사용했다.
- [ ] 파란 선과 더하기 마커를 지정했다.
- [ ] X 0-10, Y 0-25 범위를 확인했다.
:::

:::page{type="concept" id="ch12-range" layout="basic"}
# 실습 3 · 선 모양과 표시 범위

## 생성된 차트에 적용하기

```python
ax_cht1.clear()
a = [1, 2, 3, 4, 5]
b = [5, 10, 15, 20, 25]
ax_cht1.plot(a, b, "b-+", clip_on=False)
ax_cht1.axis([0, 10, 0, 25])
```
