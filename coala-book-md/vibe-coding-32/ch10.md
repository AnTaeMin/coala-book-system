# 반복과 누적 이해 2

## 10차시 · 카페인 입력 반복·누적

### 학습 목표

- 반복 입력한 카페인 양의 합계를 구할 수 있다.
- 반복 종료 조건과 누적 결과를 확인할 수 있다.

### 오늘의 시작

앞 차시의 내용을 바탕으로 학습을 이어갑니다. 이번 차시는 카페인 입력 반복·누적에 집중합니다.

:::page{type="practice-opening" id="ch05-practice-2" practice="010-1" practice-kind="실습" platform="알고플로에서 실습하기"}
# 하루 카페인 섭취량 누적하기

하루 동안 마신 음료의 카페인 양을 더해봅시다. 처음 총량을 0mg으로 정합니다. 음료의 카페인 양을 입력할 때마다 더하고, 입력이 끝나면 총량을 출력합니다.

- [ ] 처음 총 카페인 양을 0mg으로 정했다.
- [ ] 음료 입력을 반복해 총량에 더했다.
- [ ] 입력이 끝났을 때 총량을 출력했다.
:::

:::page{type="step-process" id="ch05-caffeine-code"}
# 카페인 섭취량 누적 순서

## 총량 준비

총 카페인 양을 0mg으로 시작합니다.

## 음료 값 더하기

음료의 카페인 양을 입력하고 현재 총량에 더합니다.

## 입력 반복

더 입력할 내용이 있으면 같은 작업을 반복합니다.

## 최종 총량 출력

입력이 끝나면 누적한 총량을 출력합니다.
:::
