# Matplotlib 실습 3 · 산점도

시드 20211206, X 범위 1.1부터 100.0 미만, 간격 5.0으로 데이터를 만들어봅시다. X의 1.5배에 난수를 더한 Y로 산점도를 만들고 축 이름을 함수 호출로 설정합니다.

> [!TIP]
> seed는 난수 생성의 시작 상태를 정합니다. 같은 시드와 생성 순서를 사용하면 같은 난수를 얻습니다.

- [ ] 지정한 시드와 X 범위를 사용했다.
- [ ] X의 1.5배에 난수를 더해 Y를 만들었다.
- [ ] 축 이름·random 범례·제목을 확인했다.
:::

:::page{type="concept" id="ch13-scatter" layout="basic"}
# 실습 3 · 산점도

## 생성된 차트에 적용하기

```python
import numpy as np

ax_cht1.clear()
np.random.seed(20211206)
x = np.arange(1.1, 100.0, 5.0)
y = x * 1.5 + np.random.rand(20) * 50
ax_cht1.scatter(x, y, c="red", alpha=0.5, label="random")
ax_cht1.set_xlabel("X axis")
ax_cht1.set_ylabel("Y axis")
ax_cht1.legend(loc="upper left")
ax_cht1.set_title("random")
```

# 산점도의 데이터와 축 설정

## 난수 시드 확인

seed는 난수 생성기의 상태를 정합니다. 같은 시드와 생성 순서를 사용하면 같은 난수를 얻습니다. 산점도의 X·Y 값은 코드에서 생성한 연습용 데이터입니다.

## 축 이름과 범례

ax_cht1의 set_xlabel, set_ylabel로 축 이름을 설정합니다. 예제는 clear로 그리기 영역을 초기화하고 축 이름을 X axis·Y axis로 표시합니다. random 범례와 빨간 점을 비교합니다.
