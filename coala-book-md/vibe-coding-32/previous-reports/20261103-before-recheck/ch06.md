# 문제를 단계별로 나누기 2

## 6차시 · 앱 아이디어를 단계로 설계

### 학습 목표

- 앱 아이디어를 입력·처리·출력으로 설계할 수 있다.
- 처리 순서를 확인하고 빠진 단계를 보완할 수 있다.

### 오늘의 시작

앞 차시의 내용을 바탕으로 학습을 이어갑니다. 이번 차시는 앱 아이디어를 단계로 설계에 집중합니다.
:::

:::page{type="practice-opening" id="ch03-practice-1" practice="006-1" practice-kind="실습" platform="알고플로에서 실습하기"}
# 내 아이디어를 단계별로 나눠보기

감정 기록 앱을 입력·처리·출력으로 나누어봅시다. 오늘의 기분을 입력하고 감정 상태를 분류한 뒤 결과를 보여주는 순서로 정리합니다.

> [!TIP]
> 감정 분류는 프로그램 구조를 배우기 위한 예시입니다.

- [ ] 입력할 내용을 정리했다.
- [ ] 입력 뒤 처리할 작업을 정리했다.
- [ ] 마지막에 보여줄 결과를 정리했다.
:::

:::page{type="step-process" id="ch03-design"}
# 아이디어를 실행 순서로 만들기

## 입력 정하기

오늘의 기분을 어떤 선택 항목으로 받을지 정합니다.

## 처리 정하기

선택한 항목을 기록하고, 항목에 대응하는 안내를 준비합니다.

## 출력 정하기

선택한 기분과 기록 완료 안내를 보여줍니다.
:::

:::page{type="practice-checklist" id="ch03-check"}
# 실습 완료 확인

- [ ] 각 작업의 순서를 정리했다.

> [!KEY_POINT]
> 정리한 입력·처리·출력과 실행 순서를 확인하고 기록합니다.
