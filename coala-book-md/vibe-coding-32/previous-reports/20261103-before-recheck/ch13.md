# 반복과 조건 함께 사용하기 1

## 13차시 · 학생 수만큼 합격 판정

### 학습 목표

- 입력한 학생 수만큼 점수 처리를 반복할 수 있다.
- 80점 기준에 따라 PASS와 FAIL을 구분할 수 있다.

### 오늘의 시작

이번 차시의 주제는 학생 수만큼 합격 판정입니다.
:::

:::page{type="comparison" id="ch07-roles"}
# 반복과 조건의 서로 다른 역할

| 구조 | 점수 확인 예시 |
|---|---|
| 반복 | 학생 점수를 한 명씩 확인 |
| 조건 | 기준 점수 이상인지 확인 |
| 출력 | 그 학생의 결과를 표시 |
:::

:::page{type="practice-opening" id="ch07-practice-1" practice="013-1" practice-kind="실습" platform="알고플로에서 실습하기"}
# 입력받은 학생 수만큼 점수 통과 여부 확인

학생 수 N을 정하고 각 학생의 점수를 입력받아봅시다. 80점 이상이면 PASS, 80점 미만이면 FAIL을 출력합니다. 입력받은 N명 모두에게 결과를 출력합니다.

- [ ] 입력받은 학생 수 N만큼 처리했다.
- [ ] 80점 이상과 미만을 구분했다.
- [ ] 학생마다 PASS 또는 FAIL을 출력했다.
:::

:::page{type="step-process" id="ch07-pass-code"}
# 학생 수 N에 따라 점수 확인하기

## 학생 수 정하기

처리할 학생 수 N을 입력받고 반복 변수를 0에서 시작합니다.

## 점수 입력

학생 한 명의 점수를 입력받습니다.

## 통과 여부 출력

80점 이상이면 PASS, 80점 미만이면 FAIL을 출력합니다.

## 다음 학생 처리

반복 변수를 1 증가시키고 N명 처리가 끝날 때까지 반복합니다.
:::
