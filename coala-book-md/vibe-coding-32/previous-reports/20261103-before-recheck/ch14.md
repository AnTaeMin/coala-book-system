# 반복과 조건 함께 사용하기 2

## 14차시 · 영화 관람 반복과 분기

### 학습 목표

- 네 학생의 나이를 반복 입력하고 관람 조건을 판단할 수 있다.
- 15세 기준의 분기와 반복 흐름을 순서도로 설명할 수 있다.

### 오늘의 시작

앞 차시의 내용을 바탕으로 학습을 이어갑니다. 이번 차시는 영화 관람 반복과 분기에 집중합니다.

# 영화 관람 가능 여부 확인하기

## 네 학생의 나이 입력

학생 네 명의 나이를 하나씩 입력받습니다.

## 관람 조건 판단

15세 이상 조건을 확인합니다.

## 결과 출력

## 네 번 반복

네 학생 모두에게 결과가 출력되었는지 확인합니다.

:::page{type="flowchart" id="ch07-movie-flow" height="1050"}
# 영화 관람의 반복과 분기

학생 네 명의 나이를 입력받고 관람 조건을 판단하는 흐름입니다.

```flowchart
control_structure: loop
nodes:
  - id: start
    role: declaration
    text: i = 0, age = 0
  - id: loop
    role: decision
    text: i < 4인가?
  - id: input
    role: input
    text: 학생 나이 입력
  - id: condition
    role: decision
    text: age < 15인가?
  - id: yes
    role: output
    text: 관람불가 출력
  - id: no
    role: output
    text: 관람가능 출력
  - id: next
    role: process
    text: i = i + 1
connections:
  - from: start
    to: loop
  - from: loop
    to: input
    label: YES
  - from: input
    to: condition
  - from: condition
    to: yes
    label: YES
  - from: condition
    to: no
    label: NO
  - from: yes
    to: next
  - from: no
    to: next
  - from: next
    to: loop
```

반복 상자 안에서 나이 입력·판단·결과 출력을 네 번 수행합니다. age < 15가 참이면 관람불가, 거짓이면 관람가능입니다.
:::
