:::page{type="concept" id="ch11-index" layout="basic"}
# 왜 위치 번호에서 1을 뺄까?

## 화면의 번호

사용자는 첫 번째 행을 1행이라고 부릅니다. Python 리스트의 첫 위치는 0입니다. 따라서 화면의 2행은 리스트 위치 1과 대응합니다.

## 확인할 범위

번호를 숫자로 바꾼 뒤 실제 행과 열 범위에 있는지 확인합니다. 번호 0을 허용하면 1을 뺐을 때 -1이 되어 마지막 위치를 가리킬 수 있습니다.
:::

:::page{type="step-process" id="ch11-index-code"}
# 행·열 번호를 리스트 위치로 바꾸기

## 화면 번호 확인

화면에서 2행을 선택했다고 생각해봅시다.

## 리스트 위치 변환

첫 행의 인덱스는 0, 둘째 행의 인덱스는 1입니다. 선택한 행·열 번호에서 각각 1을 뺍니다.

## 선택한 셀 확인

변환한 행과 열 위치가 원하는 DataCell에 해당하는지 확인합니다.
:::

:::page{type="step-process" id="ch11-practice-2"}
# 표의 값 변경 순서

## 수정용 위젯 추가

앞 차시의 성적표에 Field 세 개를 추가하고 edit_row(행 번호), edit_column(열 번호), edit_value(변경할 값)로 이름을 정합니다. btn2(셀 변경) 버튼도 추가합니다. 표에는 먼저 학생 기록을 한 행 이상 넣습니다.

## 행·열 입력

edit_row와 edit_column에 바꿀 셀의 행·열 번호를 1부터 입력합니다.

## 값 입력

edit_value에 해당 셀에 넣을 값을 입력합니다.

## 인덱스 변환

btn2의 클릭 이벤트에서 번호를 숫자로 바꾸고 실제 행·열 범위에 있는지 확인합니다. 번호가 0이거나 범위를 벗어나면 변경하지 않고 안내합니다. 유효한 번호에서 각각 1을 빼서 리스트 위치로 바꿉니다.

## 변경 반영

btn2를 누르면 선택한 DataCell의 내용을 edit_value의 값으로 바꾸고 표를 갱신하도록 요청합니다. 과목 점수는 0~100 사이의 숫자인지도 확인합니다.

## 실행 확인

선택한 셀만 새 값으로 바뀌고 다른 셀은 유지되는지 확인합니다. 0이나 없는 행·열 번호를 넣었을 때 표가 바뀌지 않는지도 확인합니다.
:::
