# AI 디지털 리터러시
## 좋은 질문이 좋은 답을 만든다

### 학습 목표

- 생성형 AI의 개념을 설명할 수 있다.
- AI가 잘하는 것과 어려워하는 것을 구분할 수 있다.
- AI가 제공한 정보를 검증하고 윤리적으로 활용할 수 있다.
- 원하는 결과를 얻기 위한 구체적인 프롬프트를 작성할 수 있다.
- 앱의 목적에 맞는 입력 데이터를 설계할 수 있다.

### 생성형 AI란 무엇일까?

여러분은 이미 다양한 AI 서비스를 사용하고 있을지도 모릅니다.

- 챗GPT에게 질문하기
- 유튜브 추천 영상 보기
- 번역기와 스마트폰 음성비서 사용하기
- 쇼핑몰 추천 상품 보기

그중 **생성형 AI(Generative AI)**는 사용자의 질문이나 요청에 따라 새로운 결과물을 만들어내는 AI입니다.
:::

:::page{type="comparison" id="ch01-ai-strengths"}
# AI가 잘하는 것과 어려워하는 것

AI는 매우 똑똑해 보이지만 모든 것을 완벽하게 하지는 못합니다.

| AI가 잘하는 것 | AI가 어려워하는 것 |
|---|---|
| 빠르게 정보 정리하기 | 최신 정보는 틀릴 수 있음 |
| 아이디어 제안하기 | 사람의 감정을 이해하지 못함 |
| 반복 업무 처리하기 | 편향된 결과를 줄 수 있음 |

> [!TIP]
> AI가 잘하는 일은 맡기고, 어려워하는 일은 사람이 한 번 더 확인해야 합니다.
:::

:::page{type="concept" id="ch01-hallucination" layout="basic"}
# AI 환각

## 자신 있게 틀리는 AI

AI는 때때로 사실이 아닌 내용을 자신 있게 말합니다. 이 현상을 **AI 환각(Hallucination)**이라고 합니다.

## 예시)

```prompt
한국 최초의 스마트폰은 1995년에 출시되었나요?
```

```response
네, 맞습니다.
```

이 답변은 실제로는 틀린 정보일 수 있습니다. AI의 말투가 확신에 차 있어도, 중요한 정보는 다른 자료로 다시 확인해야 합니다.

> [!KEY_POINT]
> AI가 자신 있게 말한다고 해서 항상 맞는 것은 아닙니다.
:::

:::page{type="comparison" id="ch01-ethics"}
# AI 윤리

AI를 사용할 때는 올바른 태도가 필요합니다. 다음 세 가지를 지켜봅시다.

| 주의할 점 | 이렇게 실천해요 |
|---|---|
| 개인정보 보호 | 이름, 주민번호, 주소, 전화번호 등을 AI에 입력하지 않기 |
| 저작권 | AI가 만든 결과물을 그대로 복사해서 제출하지 않기 |
| 정보 검증 | AI의 답변을 믿기 전에 다른 자료로 확인하기 |
:::

:::page{type="concept" id="ch01-prompt" layout="basic"}
# 프롬프트(Prompt)란?

## 왜 같은 AI인데 답변이 다를까?

같은 AI인데도 어떤 답변은 유용하고, 어떤 답변은 아쉽습니다. 그 이유 중 하나는 **질문의 방식**에 있습니다.

AI는 우리가 입력한 질문을 바탕으로 답변을 생성합니다. 이때 AI에게 전달하는 질문, 요청, 지시문을 **프롬프트(Prompt)**라고 합니다.

## 짧은 프롬프트와 구체적인 프롬프트

- **짧은 프롬프트:** 공부 계획 알려줘
- **구체적인 프롬프트:** 시험이 2주 남았는데 하루 2시간씩 공부할 수 있어. 효율적인 공부 계획을 짜줘.

대부분 두 번째 질문이 더 구체적이고 활용하기 좋은 답변을 받을 가능성이 높습니다.

> [!KEY_POINT]
> 좋은 질문은 무엇을 원하는지 명확하고, 필요한 조건과 상황 설명이 들어 있습니다.
:::

:::page{type="comparison" id="ch01-good-prompt"}
# 좋은 프롬프트의 특징

질문이 구체적일수록 원하는 결과를 얻을 가능성이 높아집니다. 모호한 질문을 세 가지 방법으로 바꿔봅시다.

| 특징 | 모호한 질문 | 구체적인 질문 |
|---|---|---|
| 원하는 것을 명확하게 | 추천해줘 | 공부 계획을 추천해줘 |
| 상황이나 조건 알려주기 | 여행 추천해줘 | 2박 3일 부산 여행 코스를 추천해줘. 실내 활동 위주로 알려줘 |
| 대상 알려주기 | 건강 관리 방법 알려줘 | 대학생이 실천할 수 있는 건강 관리 방법 알려줘 |

> [!TIP]
> 좋은 프롬프트는 한 번에 완성되지 않을 수도 있습니다. 답변이 아쉽다면 질문을 조금 더 구체적으로 다듬어보세요.
:::

:::page{type="practice-opening" id="ch01-practice-1" practice="001-1" practice-kind="AI와 대화" platform="알고플로에서 실습하기"}
# 어떤 질문이 더 좋은 답을 만들까?

생성형 AI는 질문의 유형과 방식에 따라 다른 결과를 보여줍니다. AI가 잘 답하는 질문과 어려워하는 질문을 비교하고, 모호한 질문을 구체적으로 바꿨을 때 답이 어떻게 달라지는지 직접 확인해봅시다.

> [!TIP]
> 일반 지식, 실시간 정보, 개인 정보처럼 질문의 유형을 바꿔가며 물어보세요.
:::

:::page{type="practice-checklist" id="ch01-practice-1-check"}
# 실습 목표

- [ ] AI가 잘 답한 질문과 그렇지 않은 질문을 구분할 수 있다.
- [ ] 질문 유형에 따라 AI의 응답이 어떻게 달라지는지 설명할 수 있다.
- [ ] 모호한 질문을 구체적으로 고쳐 더 나은 답을 받을 수 있다.
:::

:::page{type="concept" id="ch01-input-data" layout="cards"}
# 어떤 입력 데이터가 필요할까?

앱의 목적에 따라 필요한 입력 데이터는 달라집니다. 먼저 "어떤 결과를 만들고 싶은가?"를 생각해야 합니다.

## 건강관리 앱

- 목표: BMI 지수 산출하기
- 입력: 키, 몸무게

## 병원 접수 앱

- 목표: 건강 상태 분석하기
- 입력: 이름, 증상, 체온

> [!KEY_POINT]
> 만들고 싶은 결과가 정해지면, 그 결과에 필요한 입력 데이터가 보입니다.
:::

:::page{type="comparison" id="ch01-app-process"}
# 앱에서는 어떻게 활용될까?

앱은 입력된 데이터를 처리해서 결과를 만들어냅니다.

| 앱 기능 | 처리 과정 |
|---|---|
| BMI 계산 | 키와 몸무게 계산 |
| 출석 체크 | 출석 여부 확인 |
| 감정 기록 | 감정 상태 분류 |
| 병원 접수 | 응급 여부 판단 |

> [!TIP]
> AI 서비스도 질문, 키워드, 이미지 같은 입력 데이터에 따라 결과가 달라집니다. 입력 데이터의 품질이 결과의 품질을 좌우합니다.
:::

:::page{type="practice-opening" id="ch01-practice-2" practice="001-2" practice-kind="데이터 실습" platform="알고플로에서 실습하기"}
# 앱에 필요한 입력 데이터 설계하기

앱을 만들기 위해서는 먼저 어떤 데이터를 입력받아야 하는지 설계해야 합니다. 앱의 목적을 하나 정하고, 그 목적에 맞는 입력 데이터를 직접 설계해봅시다.

> [!TIP]
> 어떤 데이터를 입력받을지 먼저 설계하면 앱의 기능과 구조를 더 쉽게 이해할 수 있습니다.
:::
